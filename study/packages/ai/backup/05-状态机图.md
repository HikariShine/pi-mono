# pi-ai 状态机图

## 1. AssistantMessageEventStream 状态机

```
                    ┌─────────────┐
                    │    初始     │
                    │  (created)  │
                    └──────┬──────┘
                           │
                           │ push({type:"start"})
                           ▼
                    ┌─────────────┐
        ┌───────────│   已开始    │◄─────────────────────────────┐
        │           │  (streaming)│                              │
        │           └──────┬──────┘                              │
        │                  │                                     │
        │                  │ push(event)                         │
        │                  ▼                                     │
        │           ┌─────────────┐                              │
        │           │  事件队列   │                              │
        │           │ (events[])  │                              │
        │           └──────┬──────┘                              │
        │                  │                                     │
        │                  │ 迭代器拉取                          │
        │                  ▼                                     │
        │           ┌─────────────┐                              │
        │           │  事件消费   │                              │
        │           │ (iterator)  │                              │
        │           └──────┬──────┘                              │
        │                  │                                     │
        │                  │ push(...) 继续                      │
        └──────────────────┘                                     │
                           │                                     │
                           │ end(message?)                       │
                           ▼                                     │
                    ┌─────────────┐                              │
        ┌───────────│   已结束    │                              │
        │           │  (ended)    │                              │
        │           └──────┬──────┘                              │
        │                  │                                     │
        │                  │ 迭代器拉取完成                       │
        │                  ▼                                     │
        │           ┌─────────────┐                              │
        │           │  全部消费   │                              │
        │           │(done=true)  │                              │
        │           └─────────────┘                              │
        │                                                        │
        │           push(error)                                  │
        └──────────►│                                            │
                    ▼                                            │
             ┌─────────────┐                                     │
             │   错误      │─────────────────────────────────────┘
             │  (error)    │  push(event) 继续
             └─────────────┘
```

**关键行为**:
- `push(event)`: 添加事件到队列，通知等待的迭代器
- `end(message)`: 标记结束，可选提供完整消息
- `[Symbol.asyncIterator]`: 返回异步迭代器
- `result()`: 收集所有事件，返回完整消息

## 2. Provider 流处理状态机

```
                    ┌─────────────┐
                    │   开始     │
                    │ (start)    │
                    └──────┬──────┘
                           │
                           │ buildPayload()
                           ▼
                    ┌─────────────┐
                    │ 构建请求   │
                    │ (building) │
                    └──────┬──────┘
                           │
                           │ fetch()
                           ▼
                    ┌─────────────┐
                    │ 发送请求   │
                    │ (fetching) │
                    └──────┬──────┘
                           │
              ┌────────────┼────────────┐
              │            │            │
              ▼            │            ▼
       ┌────────────┐      │     ┌────────────┐
       │ 网络错误   │      │     │  HTTP 200  │
       │            │      │     │            │
       └─────┬──────┘      │     └─────┬──────┘
             │             │           │
             │             │           │ parse SSE
             ▼             │           ▼
       ┌────────────┐      │     ┌────────────┐
       │ push(error)│      │     │ 解析流    │
       │ end()      │      │     │ (parsing) │
       └────────────┘      │     └─────┬──────┘
                           │           │
                           │           │ yield event
                           │           ▼
                           │     ┌────────────┐
                           │     │ 推送事件  │
                           │     │ (pushing) │
                           │     └─────┬──────┘
                           │           │
                           │           │ SSE 结束
                           │           ▼
                           │     ┌────────────┐
                           │     │ 构建消息  │
                           └────▶│(final msg)│
                                 └─────┬──────┘
                                       │
                                       │ end(message)
                                       ▼
                                 ┌────────────┐
                                 │   完成    │
                                 │ (done)    │
                                 └────────────┘
```

## 8. 完整的请求-响应状态机

```
User Code
   │
   │ stream(model, context)
   ▼
┌─────────────┐
│ 创建流     │────────────────────────────────────────┐
│ (外层流)   │                                        │
└──────┬──────┘                                        │
       │                                               │
       │ resolveProvider                               │
       ▼                                               │
┌─────────────┐                                       │
│ 获取 Provider│                                       │
└──────┬──────┘                                       │
       │                                               │
       │ 调用 provider.stream                          │
       ▼                                               │
┌─────────────┐    ┌─────────────┐                   │
│ Provider    │───▶│ 创建内层流  │                   │
│ 实现        │    │ (inner)     │                   │
└──────┬──────┘    └──────┬──────┘                   │
       │                  │                          │
       │                  │ HTTP fetch               │
       │                  ▼                          │
       │           ┌─────────────┐                   │
       │           │ SSE 流     │                   │
       │           │ (LLM API)  │                   │
       │           └──────┬──────┘                   │
       │                  │                          │
       │                  │ parse & yield events     │
       │                  ▼                          │
       │           ┌─────────────┐                   │
       │           │ 推送事件   │───────────────────┤
       │           │ 到内层流   │                   │
       │           └─────────────┘                   │
       │                          │                  │
       │                          │ forwardStream    │
       │                          ▼                  │
       │                   ┌─────────────┐          │
       │                   │ 转发到外层流 │◄─────────┤
       │                   │ (outer)     │          │
       │                   └──────┬──────┘          │
       │                          │                 │
       └──────────────────────────┘                 │
                                  │                 │
                                  │ 用户迭代        │
                                  ▼                 │
                           ┌─────────────┐         │
                           │ for await   │─────────┘
                           │ (consume)   │
                           └─────────────┘
```
