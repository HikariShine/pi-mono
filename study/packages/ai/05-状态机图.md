# pi-ai 状态机图

## 1. EventStream 状态机

```
                    ┌─────────────┐
         ┌─────────│   INITIAL   │─────────┐
         │         │  (初始状态)  │         │
         │         └─────────────┘         │
         │                │                │
    push │                │ push           │ push
    (非   │                │ (完成          │ (空队列)
    完成) │                │ 事件)          │
         ▼                ▼                ▼
┌─────────────────┐  ┌─────────────┐  ┌─────────────────┐
│     ACTIVE      │  │    DONE     │  │    WAITING      │
│   (活跃状态)     │  │  (完成状态)  │  │  (等待消费)     │
│                 │  │             │  │                 │
│ queue: [...]    │  │ done: true  │  │ queue: []       │
│ waiting: []     │  │             │  │ waiting: [...]  │
└────────┬────────┘  └─────────────┘  └─────────────────┘
         │                                      │
         │ for await                            │ push
         ▼                                      ▼
┌─────────────────┐                    ┌─────────────────┐
│    ITERATING    │                    │     ACTIVE      │
│   (迭代状态)     │                    │   (回到活跃)    │
└─────────────────┘                    └─────────────────┘
```

**状态转换**：
- `INITIAL` → `ACTIVE`: push(event)
- `INITIAL` → `DONE`: push(完成事件)
- `INITIAL` → `WAITING`: for await (空队列)
- `ACTIVE` → `DONE`: push(完成事件)
- `ACTIVE` → `WAITING`: for await (空队列)
- `WAITING` → `ACTIVE`: push(event)
- `WAITING` → `DONE`: push(完成事件)

## 2. AssistantMessageEventStream 状态机

```
┌─────────────────────────────────────────────────────────────┐
│                       事件序列状态                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌─────────┐    ┌─────────────┐    ┌───────────────────┐  │
│   │  IDLE   │───▶│  STREAMING  │───▶│     COMPLETED     │  │
│   │ (空闲)  │    │   (流式中)   │    │      (完成)        │  │
│   └─────────┘    └──────┬──────┘    └───────────────────┘  │
│                         │                                   │
│              ┌──────────┼──────────┐                        │
│              ▼          ▼          ▼                        │
│       ┌──────────┐ ┌────────┐ ┌──────────┐                 │
│       │ TEXT     │ │THINKING│ │ TOOLCALL │                 │
│       │ (文本块)  │ │(思考块)│ │(工具调用)│                 │
│       └────┬─────┘ └───┬────┘ └────┬─────┘                 │
│            │           │           │                        │
│            └───────────┴───────────┘                        │
│                        │                                    │
│                        ▼                                    │
│                 ┌─────────────┐                             │
│                 │    DONE     │                             │
│                 │   或 ERROR  │                             │
│                 └─────────────┘                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**有效事件序列**：

```
正常文本回复:
start → text_start(0) → text_delta(0, "H") → text_delta(0, "i") → text_end(0, "Hi") → done

工具调用:
start → toolcall_start(0) → toolcall_delta(0, "{\"n") → ... → toolcall_end(0, {name, args}) → done(toolUse)

混合回复:
start → text_start(0) → text_delta(0, "...") → text_end(0) → toolcall_start(1) → ... → toolcall_end(1) → done

带思考的回复:
start → thinking_start(0) → thinking_delta(0, "...") → thinking_end(0) → text_start(1) → ... → done
```

## 3. Provider 请求状态机

```
┌────────────────────────────────────────────────────────────────┐
│                     Provider 请求生命周期                       │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│   ┌─────────┐     ┌─────────────┐     ┌─────────────────────┐ │
│   │  IDLE   │────▶│  PREPARING  │────▶│     REQUESTING      │ │
│   │ (空闲)  │     │  (准备参数)  │     │     (请求中)        │ │
│   └─────────┘     └─────────────┘     └──────────┬──────────┘ │
│                                                  │            │
│                       ┌──────────────────────────┘            │
│                       ▼                                       │
│              ┌─────────────────┐                              │
│              │   CONNECTING    │                              │
│              │   (连接建立)     │                              │
│              └────────┬────────┘                              │
│                       │                                       │
│                       ▼                                       │
│              ┌─────────────────┐                              │
│              │    STREAMING    │                              │
│              │   (接收 SSE)    │                              │
│              └────────┬────────┘                              │
│                       │                                       │
│        ┌──────────────┼──────────────┐                       │
│        ▼              ▼              ▼                       │
│   ┌─────────┐   ┌─────────┐   ┌─────────┐                   │
│   │ SUCCESS │   │  ABORT  │   │  ERROR  │                   │
│   │ (成功)  │   │ (取消)  │   │ (错误)  │                   │
│   └─────────┘   └─────────┘   └─────────┘                   │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

**状态说明**：
- `IDLE`: 初始状态
- `PREPARING`: 构建参数、转换消息格式
- `REQUESTING`: 发送 HTTP 请求
- `CONNECTING`: 等待服务器响应
- `STREAMING`: 接收 SSE 流
- `SUCCESS`: 正常完成
- `ABORT`: 用户取消 (AbortSignal)
- `ERROR`: 网络/API 错误

## 4. OAuth 认证状态机

```
┌─────────────────────────────────────────────────────────────────┐
│                     OAuth Device Flow                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ┌───────────┐     ┌───────────────┐     ┌─────────────────┐  │
│   │   IDLE    │────▶│  INITIATING   │────▶│    PENDING      │  │
│   │   (空闲)   │     │  (发起请求)   │     │  (等待用户授权) │  │
│   └───────────┘     └───────────────┘     └────────┬────────┘  │
│                                                    │           │
│                         ┌──────────────────────────┘           │
│                         ▼                                      │
│                ┌─────────────────┐                             │
│                │    POLLING      │                             │
│                │  (轮询 token)   │                             │
│                └────────┬────────┘                             │
│                         │                                      │
│        ┌────────────────┼────────────────┐                    │
│        ▼                ▼                ▼                    │
│   ┌─────────┐     ┌──────────┐     ┌──────────┐              │
│   │SUCCESS  │     │EXPIRED   │     │ DENIED   │              │
│   │(获取到  │     │(授权码   │     │ (用户    │              │
│   │token)   │     │过期)     │     │ 拒绝)    │              │
│   └────┬────┘     └──────────┘     └──────────┘              │
│        │                                                      │
│        ▼                                                      │
│   ┌─────────────────────────────────────────┐                 │
│   │           REFRESHABLE                   │                 │
│   │  (凭证有效期内，可刷新)                   │                 │
│   └────────────────────┬────────────────────┘                 │
│                        │                                      │
│                        ▼                                      │
│   ┌────────────────────────────────│   ┌─────────────────────────────────────────┐
│   │           EXPIRED                       │
│   │  (需要调用 refreshToken)                 │
│   └─────────────────────────────────────────┘
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**状态说明**：
- `IDLE`: 初始状态
- `INITIATING`: 向 OAuth 服务器请求 device code
- `PENDING`: 等待用户在浏览器授权
- `POLLING`: 轮询 access token
- `SUCCESS`: 获取凭证成功
- `EXPIRED`: 授权码过期
- `DENIED`: 用户拒绝授权
- `REFRESHABLE`: 凭证有效期内
- `REFRESH_EXPIRED`: 需要刷新 token

## 6. 错误处理状态机

```
┌─────────────────────────────────────────────────────────────────┐
│                     错误处理流程                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ┌───────────┐                                                 │
│   │   NORMAL  │                                                 │
│   │ (正常运行) │                                                 │
│   └─────┬─────┘                                                 │
│         │                                                       │
│    ┌────┴────┬────────────┬────────────┬───────────┐           │
│    ▼         ▼            ▼            ▼           ▼           │
│ ┌──────┐ ┌──────┐  ┌──────────┐  ┌─────────┐ ┌──────────┐     │
│ │NETWORK│ │ API  │  │   AUTH   │  │ RATE    │ │  VALID   │     │
│ │ERROR  │ │ERROR │  │  ERROR   │  │ LIMIT   │ │  ERROR   │     │
│ └──┬───┘ └──┬───┘  └────┬─────┘  └────┬────┘ └────┬─────┘     │
│    │        │           │             │           │            │
│    └────────┴───────────┴─────────────┴───────────┘            │
│                      │                                           │
│                      ▼                                           │
│              ┌─────────────┐                                     │
│              │  CAPTURED   │                                     │
│              │ (捕获错误)   │                                     │
│              └──────┬──────┘                                     │
│                     │                                            │
│          ┌─────────┴──────────┐                                 │
│          ▼                    ▼                                 │
│   ┌─────────────┐      ┌─────────────┐                         │
│   │   RETRY     │      │   STREAM    │                         │
│   │ (自动重试)  │      │   ERROR     │                         │
│   │             │      │ (流式返回)  │                         │
│   │ maxRetry    │      │             │                         │
│   │ DelayMs     │      │ push({      │                         │
│   │             │      │  type:      │                         │
│   └──────┬──────┘      │  "error" }) │                         │
│          │             └─────────────┘                         │
│          │                                                      │
│          ▼                                                      │
│   ┌─────────────┐                                               │
│   │   SUCCESS   │                                               │
│   │  (重试成功)  │                                               │
│   └─────────────┘                                               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**错误类型**：
- `NETWORK_ERROR`: 网络连接失败
- `API_ERROR`: API 返回错误 (4xx/5xx)
- `AUTH_ERROR`: 认证失败 (401/403)
- `RATE_LIMIT`: 速率限制 (429)
- `VALIDATION_ERROR`: 参数验证失败
