# pi-ai 类型手册

## 核心类型速查表

### Message 类型

| 类型 | 字段 | 类型 | 说明 |
|------|------|------|------|
| `UserMessage` | role | `"user"` | 固定值 |
| | content | `string \| (TextContent \| ImageContent)[]` | 纯文本或多模态 |
| | timestamp | `number` | Unix 时间戳 (ms) |
| `AssistantMessage` | role | `"assistant"` | 固定值 |
| | content | `(TextContent \| ThinkingContent \| ToolCall)[]` | 内容块数组 |
| | api | `Api` | 使用的 API |
| | provider | `Provider` | 提供商 ID |
| | model | `string` | 模型 ID |
| | responseId | `string \| undefined` | Provider 消息 ID |
| | usage | `Usage` | Token 统计 |
| | stopReason | `StopReason` | 停止原因 |
| | errorMessage | `string \| undefined` | 错误信息 |
| | timestamp | `number` | Unix 时间戳 |
| `ToolResultMessage` | role | `"toolResult"` | 固定值 |
| | toolCallId | `string` | 对应 ToolCall 的 ID |
| | toolName | `string` | 工具名称 |
| | content | `(TextContent \| ImageContent)[]` | 结果内容 |
| | details | `TDetails` | 扩展详情 |
| | isError | `boolean` | 是否出错 |
| | timestamp | `number` | Unix 时间戳 |

### Content 块类型

| 类型 | 字段 | 类型 | 说明 |
|------|------|------|------|
| `TextContent` | type | `"text"` | 固定值 |
| | text | `string` | 文本内容 |
| | textSignature | `string \| undefined` | OpenAI Responses 元数据 |
| `ThinkingContent` | type | `"thinking"` | 固定值 |
| | thinking | `string` | 推理内容 |
| | thinkingSignature | `string \| undefined` | Google opaque signature |
| | redacted | `boolean \| undefined` | 是否被安全过滤 |
| `ImageContent` | type | `"image"` | 固定值 |
| | data | `string` | Base64 编码 |
| | mimeType | `string` | `"image/jpeg"` 等 |
| `ToolCall` | type | `"toolCall"` | 固定值 |
| | id | `string` | 唯一 ID |
| | name | `string` | 工具名称 |
| | arguments | `Record<string, any>` | 参数对象 |
| | thoughtSignature | `string \| undefined` | Google 签名 |

### Context 类型

```typescript
interface Context {
  systemPrompt?: string;     // 系统提示词
  messages: Message[];       // 对话历史 (必须)
  tools?: Tool[];            // 可用工具
}
```

**约束**：
- `messages` 必须按时间顺序排列
- `tools` 为空或未定义表示无工具
- `systemPrompt` 为可选，某些 Provider 不支持

### Tool 类型

```typescript
import type { TSchema } from "@sinclair/typebox";

interface Tool<TParameters extends TSchema = TSchema> {
  name: string;              // 工具名称
  description: string;       // 工具描述
  parameters: TParameters;   // TypeBox Schema
}
```

**示例**：
```typescript
const weatherTool: Tool = {
  name: "get_weather",
  description: "获取天气",
  parameters: Type.Object({
    city: Type.String(),
    unit: Type.Optional(Type.StringEnum(["c", "f"]))
  })
};
```

### Model 类型

```typescript
interface Model<TApi extends Api> {
  id: string;                    // 模型 ID
  name: string;                  // 显示名称
  api: TApi;                     // API 类型
  provider: Provider;            // 提供商 ID
  baseUrl: string;               // API 基础 URL
  reasoning: boolean;            // 是否支持推理
  input: ("text" | "image")[];   // 支持的输入类型
  cost: {
    input: number;               // $/million tokens
    output: number;
    cacheRead: number;
    cacheWrite: number;
  };
  contextWindow: number;         // 上下文窗口大小
  maxTokens: number;             // 最大输出 tokens
  headers?: Record<string, string>;
  compat?: OpenAICompletionsCompat;  // 兼容性设置
}
```

**常用模型**：

| 模型 | Provider | API | Context | Max Tokens |
|------|----------|-----|---------|------------|
| gpt-4o | openai | openai-completions | 128K | 16384 |
| gpt-4o-mini | openai | openai-completions | 128K | 16384 |
| claude-3-5-sonnet | anthropic | anthropic-messages | 200K | 8192 |
| claude-3-opus | anthropic | anthropic-messages | 200K | 4096 |
| gemini-2.0-flash | google | google-generative-ai | 1M | 8192 |
| gemini-2.5-pro | google | google-generative-ai | 1M | 8192 |
| mistral-large | mistral | mistral-conversations | 128K | 8192 |

### Usage 类型

```typescript
interface Usage {
  input: number;          // 输入 tokens
  output: number;         // 输出 tokens
  cacheRead: number;      // 缓存读取 tokens
  cacheWrite: number;     // 缓存写入 tokens
  totalTokens: number;    // 总计
  cost: {
    input: number;        // 输入成本 ($)
    output: number;       // 输出成本 ($)
    cacheRead: number;    // 缓存读成本 ($)
    cacheWrite: number;   // 缓存写成本 ($)
    total: number;        // 总成本 ($)
  };
}
```

**成本计算示例**：
```typescript
// GPT-4o: $2.5/MTok input, $10/MTok output
const usage = {
  input: 1000, output: 500, cacheRead: 0, cacheWrite: 0,
  totalTokens: 1500, cost: { input: 0, output: 0, cacheRead: 0, cacheWrite: 0, total: 0 }
};
const cost = calculateCost(getModel("openai", "gpt-4o"), usage);
// cost.input = 0.0025, cost.output = 0.005, cost.total = 0.0075
```

### StopReason 类型

```typescript
type StopReason = 
  | "stop"      // 正常完成
  | "length"    // 达到 max_tokens 限制
  | "toolUse"   // 需要调用工具
  | "error"     // 发生错误
  | "aborted";  // 用户取消
```

### AssistantMessageEvent 类型

```typescript
type AssistantMessageEvent =
  // 流开始
  | { type: "start"; partial: AssistantMessage }
  
  // 文本块
  | { type: "text_start"; contentIndex: number; partial: AssistantMessage }
  | { type: "text_delta"; contentIndex: number; delta: string; partial: AssistantMessage }
  | { type: "text_end"; contentIndex: number; content: string; partial: AssistantMessage }
  
  // 思考块
  | { type: "thinking_start"; contentIndex: number; partial: AssistantMessage }
  | { type: "thinking_delta"; contentIndex: number; delta: string; partial: AssistantMessage }
  | { type: "thinking_end"; contentIndex: number; content: string; partial: AssistantMessage }
  
  // 工具调用块
  | { type: "toolcall_start"; contentIndex: number; partial: AssistantMessage }
  | { type: "toolcall_delta"; contentIndex: number; delta: string; partial: AssistantMessage }
  | { type: "toolcall_end"; contentIndex: number; toolCall: ToolCall; partial: AssistantMessage }
  
  // 完成/错误
  | { type: "done"; reason: "stop" | "length" | "toolUse"; message: AssistantMessage }
  | { type: "error"; reason: "aborted" | "error"; error: AssistantMessage };
```

**事件序列示例**（普通文本回复）：
```
start → text_start (index: 0) → text_delta ("He") → text_delta ("llo") → ... → text_end → done
```

**事件序列示例**（工具调用）：
```
start → toolcall_start (index: 0) → toolcall_delta ("{\"na") → ... → toolcall_end → done (reason: toolUse)
```

### StreamOptions 类型

```typescript
interface StreamOptions {
  temperature?: number;                    // 温度 (0-2)
  maxTokens?: number;                      // 最大输出 tokens
  signal?: AbortSignal;                    // 取消信号
  apiKey?: string;                         // 覆盖环境的 API Key
  transport?: "sse" | "websocket" | "auto"; // 传输方式
  cacheRetention?: "none" | "short" | "long"; // 缓存保留
  sessionId?: string;                      // 会话 ID
  headers?: Record<string, string>;        // 自定义头
  onPayload?: (payload: unknown, model: Model) => unknown; // 修改请求体
  maxRetryDelayMs?: number;                // 最大重试等待
  metadata?: Record<string, unknown>;      // 元数据
}
```

### CacheRetention 类型

```typescript
type CacheRetention = "none" | "short" | "long";
```

- `"none"`: 不使用缓存
- `"short"`: 短保留期（默认）
- `"long"`: 长保留期（跨请求）

**Provider 映射**：
- OpenAI: `"none"` → `"default"`, `"short"` → `"ephemeral"`, `"long"` → `"persistent"`
- Anthropic: 通过 sessionId 实现

---

### Transport 类型

```typescript
type Transport = "sse" | "websocket" | "auto";
```

**Provider 支持**：
- `anthropic-messages`: 支持 `sse` 和 `websocket`
- 其他 Provider: 通常只支持 `sse`

### OAuth 相关类型

```typescript
interface OAuthCredentials {
  accessToken: string;
  refreshToken: string;
  expires: number;           // Unix timestamp (ms)
  [key: string]: any;        // Provider 特定字段
}

interface OAuthAuthInfo {
  url: string;               // 授权 URL
  instructions?: string;     // 说明
}

interface OAuthPrompt {
  message: string;
  placeholder?: string;
}

interface OAuthLoginCallbacks {
  onAuth: (info: OAuthAuthInfo) => void;
  onPrompt: (prompt: OAuthPrompt) => Promise<string>;
  onProgress: (message: string) => void;
}

interface OAuthProviderInterface {
  id: string;
  name: string;
  login: (callbacks: OAuthLoginCallbacks) => Promise<OAuthCredentials>;
  refreshToken: (credentials: OAuthCredentials) => Promise<OAuthCredentials>;
  getApiKey: (credentials: OAuthCredentials) => string;
}
```

## 类型转换关系图

```
User Input
    │
    ├──▶ string ──▶ TextContent
    │
    ├──▶ Image URL/File ──▶ ImageContent (base64)
    │
    └──▶ Tool Definition ──▶ Tool (TypeBox Schema)

Context
    │
    ├──▶ messages: Message[]
    ├──▶ tools?: Tool[]
    └──▶ systemPrompt?: string

Provider
    │
    ├──▶ OpenAI ──▶ ChatCompletionMessageParam[]
    ├──▶ Anthropic ──▶ MessageParam[]
    ├──▶ Google ──▶ Content[]
    └──▶ Mistral ──▶ ChatCompletionMessageParam[]

Response
    │
    └──▶ Provider Native Format ──▶ AssistantMessageEventStream
             │
             └──▶ Events ──▶ AssistantMessage
```
