

## 7. 类型转换关系图

```
SimpleStreamOptions
    │
    ├── reasoning: "minimal" ──▶ OpenAI: reasoning.effort="low"
    │                             Anthropic: thinking.budget_tokens=1024
    │                             Google: thinkingLevel=LOW
    │
    ├── reasoning: "medium" ──▶ OpenAI: reasoning.effort="medium"
    │                             Anthropic: thinking.budget_tokens=16000
    │                             Google: thinkingLevel=MEDIUM
    │
    └── ...

Context.messages
    │
    ├── UserMessage ──▶ Provider-specific format
    │   ├── text ────▶ OpenAI: {role:"user", content:"..."}
    │   ├── image ───▶ OpenAI: {role:"user", content:[{type:"image",...}]}
    │
    └── AssistantMessage ──▶ Provider-specific format
        ├── text ────▶ OpenAI: {role:"assistant", content:"..."}
        └── tool ────▶ OpenAI: {role:"assistant", tool_calls:[...]}

Provider SSE
    │
    ├── response.output_text.delta ──▶ text_delta
    ├── response.reasoning.delta ────▶ thinking_delta
    ├── response.function_call ──────▶ toolcall_delta / toolcall_end
    └── response.completed ──────────▶ done
```

## 8. 类型安全要点

| 场景 | 类型 | 注意事项 |
|------|------|----------|
| Model.api | `Api` | 使用字面量类型，自动补全 |
| Model.provider | `Provider` | 同上 |
| Context.messages | `Array<UserMessage \| AssistantMessage>` | 区分用户和助手消息 |
| Tool.parameters | `TSchema` | 使用 TypeBox，非普通对象 |
| Event.type | 联合类型 | switch 需要穷尽检查 |
| StopReason | 联合类型 | 处理所有可能值 |
