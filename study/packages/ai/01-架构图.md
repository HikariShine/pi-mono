# pi-ai 架构图

## 项目概述

**pi-ai** 是一个统一的 LLM API 库，提供跨多提供商的标准化接口。支持 20+ 个 LLM 提供商，包括 OpenAI、Anthropic、Google、Azure、Mistral 等。

---

## 导出结构 (index.ts)

```typescript
// TypeBox 类型工具
export { Type, Static, TSchema } from "@sinclair/typebox";

// 核心 API

export * from "./env-api-keys.js";      // 环境变量密钥

export * from "./stream.js";            // stream/complete API

// Provider 类型
export { AnthropicOptions } from "./providers/anthropic.js";
export { OpenAICompletionsOptions } from "./providers/openai-completions.js";
export { GoogleOptions } from "./providers/google.js";
// ... 更多 Provider 选项类型

// 工具函数
export * from "./utils/event-stream.js";    // 事件流
export * from "./utils/json-parse.js";      // JSON 解析
export * from "./utils/overflow.js";        // Token 溢出
export * from "./utils/validation.js";      // 参数验证
export * from "./utils/typebox-helpers.js"; // TypeBox 辅助

// OAuth 类型
export * from "./utils/oauth/types.js";
```
