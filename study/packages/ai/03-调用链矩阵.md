# pi-ai 调用链矩阵

## 调用链 1: 流式调用 (stream)

### 完整调用路径

```
stream(model, context, options)
    │
    ▼
resolveApiProvider(model.api) ──▶ getApiProvider(api)
    │
    ▼
provider.stream(model, context, options)
    │
    ▼
[Provider 特定实现，以 OpenAI Completions 为例]
    │
    ▼
streamOpenAICompletions()
    │
    ├──▶ createClient(model, context, apiKey, headers)
    │       └─▶ new OpenAI({ apiKey, baseURL })
    │
    ├──▶ buildParams(model, context, options)
    │       ├─▶ transformMessages(context.messages)  [消息格式转换]
    │       ├─▶ transformTools(context.tools)        [工具定义转换]
    │       └─▶ { model: model.id, messages, tools, temperature, ... }
    │
    ├──▶ client.chat.completions.create(params, { signal })
    │       └─▶ HTTP POST /v1/chat/completions
    │
    └──▶ for await (const chunk of openaiStream)
            ├─▶ stream.push({ type: "start", partial: output })
            ├─▶ stream.push({ type: "text_start", contentIndex, partial })
            ├─▶ stream.push({ type: "text_delta", contentIndex, delta, partial })
            ├─▶ stream.push({ type: "text_end", contentIndex, content, partial })
            └─▶ stream.push({ type: "done", reason, message })
```

## 调用链 5: 事件流 (EventStream)

### 核心机制

```
EventStream<T, R>
    │
    ├──▶ queue: T[]                    [事件队列]
    ├──▶ waiting: ((value) => void)[]  [等待的消费者回调]
    └──▶ done: boolean                 [是否结束]

push(event)
    │
    ├──▶ if done → return
    ├──▶ if isComplete(event) → done = true, resolveFinalResult
    └──▶ if waiting.length > 0 → resolve waiter
         else → queue.push(event)

[Symbol.asyncIterator]()
    │
    └──▶ while true:
         ├──▶ if queue.length > 0 → yield queue.shift()
         ├──▶ else if done → return
         └──▶ else → await new Promise(waiting.push)
```

### 代码追踪

| 调用栈 | 代码/事件 | 类型/结构定义 | 疑问 & 答案 |
|--------|-----------|---------------|-------------|
| Provider 调用 | `stream.push(event)` | `event-stream.ts:30` | Q: 如何实现 push/pull？ |
| └─> `if (this.done) return` | 检查结束状态 | `boolean` | A: 已结束不接收新事件 |
| └─> `if (isComplete(event))` | 检查是否是结束事件 | `(event: T) => boolean` | Q: 如何判断结束？ |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> [AssistantMessageEventStream] `event.type === "done" \|\| "error"` | `event-stream.ts:57` | - | A: done/error 为结束 |
| └─> `const waiter = this.waiting.shift()` | 取出等待的消费者 | `Function` | Q: 谁在等待？ |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> Consumer: `for await (const e of stream)` | async iterator | - | A: for await 会等待 |
| └─> `if (waiter) waiter({ value: event, done: false })` | 回调通知 | `IteratorResult<T>` | A: 立即交付 |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> else `this.queue.push(event)` | 入队 | `T[]` | A: 无消费者时缓存 |
| Consumer | `for await (const event of stream)` | `event-stream.ts:48` | Q: 如何暂停等待？ |
| └─> `if (queue.length > 0) yield queue.shift()` | 直接消费 | - | A: 有缓存立即返回 |
| └─> `else if (done) return` | 流已结束 | - | A: 结束迭代 |
| └─> `else await new Promise(resolve => waiting.push(resolve))` | 等待 | - | A: 注册回调等待 push |

## 关键调用链总结

| 场景 | 入口 | 核心路径 | 出口 |
