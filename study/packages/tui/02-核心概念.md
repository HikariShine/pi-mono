# pi-tui 核心概念

## 1. TUI 类

### 1.1 职责

`TUI` 是核心类，管理：
- 渲染循环 (differential rendering)
- 输入处理 (stdin)
- 焦点管理 (focus)
- 覆盖层 (overlays)
- 终端尺寸变化

### 1.2 使用方式

```typescript
import { TUI, Container, Text, ProcessTerminal } from "@mariozechner/pi-tui";

const terminal = new ProcessTerminal();
const tui = new TUI(terminal);

// 创建根容器
const root = new Container();
root.addChild(new Text("Hello TUI"));

// 启动
terminal.start(
  (data) => tui.handleInput(data),  // 输入处理
  () => tui.render()                 // 尺寸变化时重绘
);

// 设置根组件并首次渲染
tui.setComponent(root);
tui.render();

// 退出时
tui.shutdown();
terminal.stop();
```

```typescript
function isFocusable(component: Component | null): component is Component & Focusable {
```

## 3. Container 容器

### 3.1 职责

`Container` 是最基础的容器组件：
- 管理子组件列表
- 按顺序渲染子组件

```typescript
class Container implements Component {
  children: Component[] = [];

  addChild(component: Component): void;
  removeChild(component: Component): void;
  clear(): void;
  invalidate(): void;

  render(width: number): string[] {
    // 将所有子组件的行合并
    const lines: string[] = [];
    for (const child of this.children) {
      lines.push(...child.render(width));
    }
    return lines;
  }
}
```

## 4. 差异化渲染 (Differential Rendering)

### 4.1 原理

```typescript
class TUI {
  private previousFrame: string[] = [];
  private currentFrame: string[] = [];

  render(): void {
    // 1. 获取当前帧
    this.currentFrame = this.component.render(this.width);

    // 2. 与上一帧比较，生成差异
    const diff = this.computeDiff(this.previousFrame, this.currentFrame);

    // 3. 应用差异到终端
    this.applyDiff(diff);

    // 4. 保存当前帧
    this.previousFrame = this.currentFrame;
  }
}
```

### 4.2 差异计算

| 情况 | 处理 |
|------|------|
| 行相同 | 跳过 |
| 行不同 | 移动光标到行首，清除行，写入新内容 |
| 新增行 | 移动光标到行尾，换行，写入内容 |
| 删除行 | 清除多余行 |

### 4.3 优化

- 只发送变化的行，而非整个屏幕
- 行内变化时，只更新变化的部分（如果计算成本合理）
- 批量写入，减少终端 flush 次数

## 6. 焦点管理

### 6.1 机制

```typescript
class TUI {
  private focusedComponent: Component | null = null;
  private focusables: Component[] = [];  // 所有可聚焦组件

  focus(component: Component): void {
    // 1. 使当前焦点失效
    if (this.focusedComponent && isFocusable(this.focusedComponent)) {
      this.focusedComponent.focused = false;
    }

    // 2. 设置新焦点
    this.focusedComponent = component;
    if (isFocusable(component)) {
      component.focused = true;
    }

    // 3. 重新渲染（显示焦点状态）
    this.render();
  }

  nextFocus(): void {
    // Tab 顺序切换焦点
    const current = this.focusables.indexOf(this.focusedComponent);
    const next = (current + 1) % this.focusables.length;
    this.focus(this.focusables[next]);
  }
}
```

## 7. 覆盖层 (Overlay)

### 7.1 用途

- 模态对话框
- 下拉菜单
- 提示框
- 临时浮层

### 7.2 配置

```typescript
interface OverlayOptions {
  // 大小
  width?: SizeValue;        // 宽度 (数字或 "50%")
  minWidth?: number;        // 最小宽度
  maxHeight?: SizeValue;    // 最大高度

  // 定位 (anchor-based)
  anchor?: OverlayAnchor;   // "center", "top-left", "bottom-right", etc.
  offsetX?: number;         // 水平偏移
  offsetY?: number;         // 垂直偏移

  // 定位 (percentage/absolute)
  row?: SizeValue;          // 行位置 (数字或 "25%")
  col?: SizeValue;          // 列位置

  // 边距
  margin?: Margin | number;

  // 可见性控制
  visible?: (w, h) => boolean;

  // 非捕获模式 (不抢夺焦点)
  nonCapturing?: boolean;
}
```

### 7.3 使用

```typescript
const overlay = tui.showOverlay(component, {
  width: "50%",
  anchor: "center",
  margin: 2
});

// 控制
overlay.hide();           // 永久移除
overlay.setHidden(true);  // 临时隐藏
overlay.focus();          // 聚焦
overlay.unfocus();        // 释放焦点
```

### 11.1 功能

- 多行文本编辑
- 语法高亮 (通过 theme)
- 自动补全集成
- 复制粘贴
- 撤销/重做
- 搜索

### 11.2 使用

```typescript
import { Editor, type EditorOptions } from "@mariozechner/pi-tui";

const editor = new Editor({
  value: "initial text",
  language: "typescript",  // 用于语法高亮
  autocomplete: myProvider,
  onChange: (value) => console.log(value),
  onSubmit: (value) => console.log("Submitted:", value)

// 设置值
editor.setValue("new text");

// 获取值
const text = editor.getValue();

// 插入文本
editor.insertText("inserted");

// 删除选中
editor.deleteSelection();

// 全选
editor.selectAll();

// 清除
editor.clear();
```
