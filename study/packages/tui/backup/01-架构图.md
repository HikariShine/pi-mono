## 4. 差异化渲染架构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          差异化渲染流程                                      │
└─────────────────────────────────────────────────────────────────────────────┘

   用户输入 / 状态变更
          │
          ▼
   ┌──────────────┐
   │ requestRender()│ ← 请求渲染（去重：同一 tick 只渲染一次）
   └───────┬──────┘
           │ process.nextTick()
           ▼
   ┌──────────────┐
   │   doRender() │ ← 执行渲染
   └───────┬──────┘
           │
    ┌──────┴──────┬────────────────────────────────────────┐
    │             │                                        │
    ▼             ▼                                        ▼
 新组件渲染    合并弹层                                  差异化比较
    │             │                                        │
    ▼             ▼                                        ▼
render(width)  compositeOverlays()              对比 previousLines vs newLines
    │             │                                        │
    ▼             ▼                                        ▼
string[]      string[] (with overlays)          找出 firstChanged/lastChanged
                                                         │
                              ┌──────────────────────────┼──────────────────┐
                              │                          │                  │
                              ▼                          ▼                  ▼
                        全量重绘                      增量更新           仅光标移动
                    (fullRender(true))               (diff)            (no change)
                              │                          │                  │
                              ▼                          ▼                  ▼
                      CSI 2026h                           移动光标          定位硬件
                   CSI 2J (清屏)                      CSI nB/A           光标
                      输出所有行                       清除行 CSI 2K
                      CSI 2026l                       输出变更行
                                                         CSI 2026l
```

## 7. 关键技术点

| 技术 | 说明 | 代码位置 |
|------|------|----------|
| 差异化渲染 | 只更新变更的行，减少闪烁 | `tui.ts:doRender()` |
| CSI 2026 | 同步输出协议，原子化屏幕更新 | `tui.ts:fullRender()` |
| Kitty 键盘协议 | 支持按键释放/重复事件 | `keys.ts` |
| 括号粘贴模式 | 处理大段粘贴 | `terminal.ts` |
| 终端图片协议 | Kitty/iTerm2 图片显示 | `terminal-image.ts` |
| 硬件光标定位 | IME 候选窗定位 | `tui.ts:positionHardwareCursor()` |
