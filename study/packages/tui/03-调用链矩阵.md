## 关键调用链总结

| 场景 | 入口 | 核心路径 | 出口 |
|------|------|----------|------|
| **启动 TUI** | `tui.start()` | `terminal.start()` → `doRender()` → `fullRender()` | 屏幕显示 |
| **键盘输入** | `stdin` → `handleInput()` | `matchesKey()` → `Editor.handleInput()` → `requestRender()` | 状态更新+重绘 |
| **差异化渲染** | `requestRender()` | `doRender()` → 比较行 → 增量更新 | 屏幕更新 |
| **显示弹层** | `showOverlay()` | 压栈 → `compositeOverlays()` → 合成 | 弹层显示 |
| **关闭弹层** | `overlayHandle.hide()` | 出栈 → `setFocus(preFocus)` → 重绘 | 弹层消失 |
| **IME 定位** | `Editor.render()` | 插入 `CURSOR_MARKER` → `extractCursorPosition()` → `positionHardwareCursor()` | 光标定位 |
