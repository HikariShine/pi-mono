# pi-tui 调用链矩阵

## 调用链 1: TUI 初始化与渲染

### 完整调用路径

```
new TUI(terminal)
    │
    ├──▶ 初始化成员变量
    │       ├─▶ this.terminal = terminal
    │       ├─▶ this.previousFrame = []
    │       └─▶ this.currentFrame = []
    │
tui.setComponent(root)
    │
    └──▶ this.component = root

tui.render()
    │
    ├──▶ this.component.render(this.width)
    │       │
    │       ├─▶ Container.render()
    │       │       └─▶ 递归渲染子组件
    │       │
    │       └─▶ 返回 string[] (所有行)
    │
    ├──▶ this.currentFrame = renderedLines
    │
    ├──▶ this.computeDiff(previousFrame, currentFrame)
    │       │
    │       └─▶ 逐行比较，生成差异
    │
    ├──▶ this.applyDiff(diff)
    │       │
    │       ├─▶ 生成转义序列
    │       │       ├─▶ 移动光标: \x1b[<row>;<col>H
    │       │       ├─▶ 清除行: \x1b[K
    │       │       └─▶ 写入新行
    │       │
    │       └─▶ this.terminal.write(output)
    │
    └──▶ this.previousFrame = this.currentFrame
```

## 调用链 4: 键盘序列解析

### 调用路径

```
keys.ts 解析流程
    │
    ├──▶ parseKey(data)
    │       │
    │       ├──▶ 如果是 Kitty 格式:
    │       │       │
    │       │       ├──▶ 匹配: \x1b[<key>;...u
    │       │       │
    │       │       ├──▶ 解析: key code
    │       │       │
    │       │       ├──▶ 解析: modifiers (Shift/Ctrl/Alt)
    │       │       │
    │       │       ├──▶ 解析: event type (press/repeat/release)
    │       │       │
    │       │       └──▶ 返回 KeyId
    │       │
    │       └──▶ 如果是传统格式:
    │               │
    │               ├──▶ 匹配已知序列
    │               │       ├─▶ \x1b[A = Up
    │               │       ├─▶ \x1b[B = Down
    │               │       ├─▶ \x1b[3~ = Delete
    │               │       └─▶ ...
    │               │
    │               └──▶ 返回 KeyId
    │
    └──▶ matchesKey(data, keyId)
            │
            └──▶ parseKey(data) === keyId

// Key ID 格式:
// "a" = 普通按键
// "Ctrl+c" = Ctrl + c
// "Ctrl+Shift+c" = Ctrl + Shift + c
// "Alt+x" = Alt + x
// "F1" = F1
// "Up" = 上箭头
```

### 代码追踪

| 调用栈 | 代码/事件 | 类型/结构定义 | 疑问 & 答案 |
|--------|-----------|---------------|-------------|
| 解析 | `parseKey("\x1b[13;5u")` | `keys.ts` | Q: 这是什么？ |
| └─> Kitty 序列 | - | - | A: Enter + Ctrl |
| └─> 匹配正则 | `/\x1b\[(\d+);(\d+)u/` | - | - |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> code=13, mods=5 | - | - | Q: mods=5？ |
| &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;└─> Ctrl(4) + Shift(1) + 基础(0) | - | - | A: 位掩码 |
| └─> 返回 `"Ctrl+Enter"` | `KeyId` | `string` | - |
| 匹配 | `matchesKey(data, Key.Ctrl("c"))` | `keys.ts` | - |
| └─> 解析并比较 | - | - | A: 相等即匹配 |
| 返回 | `boolean` | - | A: 是否匹配 |

## 调用链 10: 终端启动与关闭

### 调用路径

```
ProcessTerminal.start(onInput, onResize)
    │
    ├──▶ 保存之前的 stdin 状态
    │       └─▶ this.wasRaw = process.stdin.isRaw
    │
    ├──▶ 启用原始模式
    │       ├─▶ process.stdin.setRawMode(true)
    │       └─▶ process.stdin.resume()
    │
    ├──▶ 设置编码
    │       └─▶ process.stdin.setEncoding("utf8")
    │
    ├──▶ 启用 bracketed paste mode
    │       └─▶ \x1b[?2004h
    │
    ├──▶ 设置 SIGWINCH 处理 (resize)
    │       └─▶ process.stdout.on("resize", onResize)
    │
    ├──▶ Windows VT 输入模式 (Windows 平台)
    │       └─▶ enableWindowsVTInput()
    │
    ├──▶ 查询并启用 Kitty 协议
    │       └─▶ queryAndEnableKittyProtocol()
    │
    └──▶ 设置 stdin 数据处理
            └─▶ this.setupStdinBuffer()

ProcessTerminal.stop()
    │
    ├──▶ 恢复原始模式
    │       └─▶ process.stdin.setRawMode(this.wasRaw)
    │
    ├──▶ 禁用 bracketed paste mode
    │       └─▶ \x1b[?2004l
    │
    ├──▶ 禁用 Kitty 协议
    │       └─▶ \x1b[<1u
    │
    ├──▶ 移除事件监听器
    │
    └──▶ 清空屏幕并显示光标
            └─▶ \x1b[2J\x1b[H + showCursor()
```
