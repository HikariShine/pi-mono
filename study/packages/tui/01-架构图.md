# pi-tui 架构图

## 项目概述

**pi-tui** 是一个终端用户界面 (TUI) 库，提供：
- 差异化渲染 (Differential Rendering) 实现高效终端更新
- 组件化架构 (Component-based)
- 支持 Kitty 键盘协议
- 终端图像显示 (Kitty/iTerm2)
- 覆盖层 (Overlay) 系统
- 丰富的内置组件

## 差异化渲染 (Differential Rendering)

```
┌─────────────────────────────────────────────────────────────────────┐
│                     差异化渲染流程                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Previous Frame          Current Frame           Diff               │
│  ┌─────────────┐        ┌─────────────┐        ┌─────────────┐     │
│  │ Hello World │        │ Hello TUI   │        │ Move cursor │     │
│  │ Line 2      │        │ Line 2      │        │ to (6,0)    │     │
│  │ Line 3      │        │ Line 3 New  │        │ Write "TUI" │     │
│  │             │        │             │        │ Clear line  │     │
│  └─────────────┘        └─────────────┘        └─────────────┘     │
│                                                                     │
│  TUI.render()                                                       │
│       │                                                             │
│       ├──▶ 调用每个组件的 render(width) → string[]                  │
│       │                                                             │
│       ├──▶ 比较新旧帧: line by line                                 │
│       │       ├─▶ 相同行: 跳过                                      │
│       │       ├─▶ 不同行: 计算差异                                  │
│       │       └─▶ 新增行: 直接写入                                  │
│       │                                                             │
│       ├──▶ 生成转义序列:                                            │
│       │       ├─▶ \x1b[<row>;<col>H  (移动光标)                     │
│       │       ├─▶ \x1b[K            (清除行)                        │
│       │       └─▶ 新行内容                                          │
│       │                                                             │
│       └──▶ terminal.write(output)                                   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 核心组件职责

| 组件 | 文件 | 职责 |
|------|------|------|
| **TUI** | `tui.ts` | 主类，渲染循环、差异比较、输入分发、焦点管理 |
| **Container** | `tui.ts` | 容器组件，管理子组件列表 |
| **Terminal** | `terminal.ts` | 终端抽象，原始模式、Kitty 协议、输入处理 |
| **Keys** | `keys.ts` | 键盘序列解析，Key ID 生成，Kitty 协议支持 |
| **Keybindings** | `keybindings.ts` | 快捷键定义、匹配、冲突检测 |
| **StdinBuffer** | `stdin-buffer.ts` | 输入缓冲，批处理输入分割 |
| **Editor** | `components/editor.ts` | 多行编辑器，语法高亮，自动补全 |
| **SelectList** | `components/select-list.ts` | 选择列表，模糊搜索 |
| **Image** | `terminal-image.ts` | Kitty/iTerm2 图像协议支持 |
| **Utils** | `utils.ts` | 文本宽度、截断、换行、ANSI 处理 |

## Kitty 键盘协议支持

```
┌─────────────────────────────────────────────────────────────────────┐
│                     Kitty 键盘协议流程                               │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1. Query 阶段                                                      │
│     ┌─────────┐    \x1b[?u          ┌─────────┐                    │
│     │  TUI    │ ──────────────────▶ │Terminal │                    │
│     │         │                     │         │                    │
│     │         │ ◀────────────────── │         │                    │
│     │         │    \x1b[?<flags>u   │         │                    │
│     └─────────┘                     └─────────┘                    │
│                                                                     │
│  2. Enable 阶段 (如果支持)                                          │
│     ┌─────────┐    \x1b[>7u         ┌─────────┐                    │
│     │  TUI    │ ──────────────────▶ │Terminal │                    │
│     │         │  (flags: 1|2|4|7)   │         │                    │
│     └─────────┘                     └─────────┘                    │
│                                                                     │
│  3. Input 阶段                                                      │
│     ┌─────────┐    \x1b[<key>;...u  ┌─────────┐                    │
│     │ Terminal│ ──────────────────▶ │  TUI    │                    │
│     │         │  (完整按键信息)      │         │                    │
│     └─────────┘                     └─────────┘                    │
│                                                                     │
│  Flags:                                                             │
│  - 1: disambiguate escape codes                                     │
│  - 2: report event types (press/repeat/release)                     │
│  - 4: report alternate keys                                         │
│  - 7: base layout key (non-Latin 键盘)                              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
