# coding-agent 架构图

## 项目概述

**coding-agent** (别名 `pi`) 是一个 AI 驱动的编码助手 CLI 工具，基于 `@mariozechner/pi-agent-core` 和 `@mariozechner/pi-ai` 构建。提供交互式 TUI、打印模式和 RPC 模式三种运行方式。

## 数据流架构

```
User Input (TUI/CLI/RPC)
    │
    ▼
┌───────────────────────────────────────────────┐
│           AgentSession.prompt()               │
│                                               │
│  ┌─────────────────────────────────────────┐  │
│  │ 1. Build Context (system + messages)   │  │
│  │ 2. Run Extensions (before_agent_start) │  │
│  │ 3. Call pi-agent-core Agent            │  │
│  │ 4. Handle Tool Calls                   │  │
│  │ 5. Persist to Session File             │  │
│  └─────────────────────────────────────────┘  │
└───────────────────┬───────────────────────────┘
                    │
        ┌───────────┼───────────┐
        ▼           ▼           ▼
   ┌─────────┐ ┌─────────┐ ┌─────────┐
   │  Tools  │ │ Skills  │ │Compact  │
   │Execution│ │Invocation│ │ (如果需要)│
   └─────────┘ └─────────┘ └─────────┘
                    │
                    ▼
            ┌───────────────┐
            │ Session File  │
            │ (~/.pi/agent/ │
            │  sessions/)   │
            └───────────────┘
```

## 核心组件职责

| 组件 | 文件 | 职责 |
|------|------|------|
| **AgentSession** | `agent-session.ts` | 核心抽象，管理 Agent 生命周期、事件订阅、模型切换、压缩、会话切换 |
| **SessionManager** | `session-manager.ts` | 会话文件读写、会话树结构管理、分支操作 |
| **ExtensionRunner** | `extensions/runner.ts` | 扩展生命周期管理、事件分发、命令注册 |
| **SettingsManager** | `settings-manager.ts` | 用户设置管理、持久化 |
| **Tool System** | `tools/*.ts` | 内置工具实现 (read, bash, edit, write, grep, find, ls) |
| **Skill System** | `skills.ts` | Skill 发现、加载、解析 |
| **Compaction** | `compaction/*.ts` | 上下文压缩、摘要生成、历史清理 |
