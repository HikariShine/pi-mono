## 4. 数据流向图

### 4.1 启动流程

```
cli.ts
  ↓
main.ts:main()
  ↓
┌──────────────────────────────────────────┐
│ 1. parseArgs()                           │
│ 2. runMigrations()                       │
│ 3. create ResourceLoader                 │
│    └── load extensions/skills/themes     │
│ 4. create SessionManager                 │
│ 5. create ModelRegistry                  │
│ 6. createAgentSession()                  │
│    └── AgentSession constructor          │
│        └── _buildRuntime()               │
│ 7. 根据 mode 选择运行方式                │
│    ├── InteractiveMode.run()             │
│    ├── runPrintMode()                    │
│    └── runRpcMode()                      │
└──────────────────────────────────────────┘
```

```
用户输入
  ↓
InteractiveMode._submitMessage()
  ↓
AgentSession.prompt()
  ↓
┌──────────────────────────────────────────┐
│ 1. 触发 before_agent_start 事件          │
│ 2. 构建 system prompt                    │
│ 3. 调用 agent.prompt()                   │
│    └── pi-agent-core Agent               │
│        └── LLM API 调用                  │
│ 4. 流式响应处理                          │
│    ├── message_update                    │
│    ├── tool_call                         │
│    ├── tool_execution                    │
│    └── tool_result                       │
│ 5. 自动压缩检查                          │
│ 6. 会话持久化                            │

  ↓
UI 更新 (TUI)
