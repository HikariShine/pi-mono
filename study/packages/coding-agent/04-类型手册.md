# coding-agent 类型手册

## 核心类型速查表

### AgentSession 相关

| 类型 | 字段 | 类型 | 说明 |
|------|------|------|------|
| `AgentSessionConfig` | agent | `Agent` | pi-agent-core Agent 实例 |
| | sessionManager | `SessionManager` | 会话管理器 |
| | settingsManager | `SettingsManager` | 设置管理器 |
| | cwd | `string` | 当前工作目录 |
| | scopedModels | `Array<{model, thinkingLevel}>` | Ctrl+P 循环模型 |
| | resourceLoader | `ResourceLoader` | 资源加载器 |
| | customTools | `ToolDefinition[]` | 自定义工具 |
| | modelRegistry | `ModelRegistry` | 模型注册表 |
| | baseToolsOverride | `Record<string, AgentTool>` | 覆盖基础工具 |
| | extensionRunnerRef | `{ current?: ExtensionRunner }` | 扩展运行时引用 |

### Session Entry 类型

```typescript
interface SessionEntryBase {
  type: string;
  id: string;
  parentId: string | null;
  timestamp: string;
}

// 消息 entry
interface SessionMessageEntry extends SessionEntryBase {
  type: "message";
  message: AgentMessage;  // pi-agent-core
}

// 推理级别变更
interface ThinkingLevelChangeEntry extends SessionEntryBase {
  type: "thinking_level_change";
  thinkingLevel: string;
}

// 模型变更
interface ModelChangeEntry extends SessionEntryBase {
  type: "model_change";
  provider: string;
  modelId: string;
}

// 压缩摘要
interface CompactionEntry<T = unknown> extends SessionEntryBase {
  type: "compaction";
  summary: string;
  firstKeptEntryId: string;
  tokensBefore: number;
  details?: T;
  fromHook?: boolean;
}

// 分支摘要
interface BranchSummaryEntry<T = unknown> extends SessionEntryBase {
  type: "branch_summary";
  fromId: string;
  summary: string;
  details?: T;
  fromHook?: boolean;
}

// 扩展自定义数据
interface CustomEntry<T = unknown> extends SessionEntryBase {
  type: "custom";
  customType: string;
  data?: T;
}

// 扩展自定义消息
interface CustomMessageEntry<T = unknown> extends SessionEntryBase {
  type: "custom_message";
  customType: string;
  content: string | (TextContent | ImageContent)[];
  details?: T;
  display: boolean;
}

// 用户标记
interface LabelEntry extends SessionEntryBase {
  type: "label";
  targetId: string;
  label?: string;
}

// 会话信息
interface SessionInfoEntry extends SessionEntryBase {
  type: "session_info";
  name?: string;
}

type SessionEntry = 
  | SessionMessageEntry 
  | ThinkingLevelChangeEntry 
  | ModelChangeEntry
  | CompactionEntry 
  | BranchSummaryEntry 
  | CustomEntry
  | CustomMessageEntry 
  | LabelEntry 
  | SessionInfoEntry;
```

### Extension 相关

```typescript
// 扩展接口
interface Extension {
  name: string;
  version: string;
  description?: string;
  
  // 生命周期
  setup?(api: ExtensionAPI): void | Promise<void>;
  initialize?(context: ExtensionContext): void | Promise<void>;
  shutdown?(): void | Promise<void>;
  
  // 事件处理器
  onAgentStart?(event: AgentStartEvent): void | Promise<void>;
  onTurnStart?(event: TurnStartEvent): void | Promise<void>;
  onToolCall?(event: ToolCallEvent): Promise<ToolCallEventResult | void>;
  onMessageEnd?(event: MessageEndEvent): void | Promise<void>;
  // ... 更多事件
}

// 扩展 API
interface ExtensionAPI {
  registerCommand(name: string, handler: CommandHandler): void;
  registerTool(definition: ToolDefinition): void;
  sendUserMessage(content: string): Promise<void>;
  showDialog(options: ExtensionUIDialogOptions): Promise<string>;
  getSessionContext(): SessionContext;
  addKeybinding(keybinding: AppKeybinding): void;
  // ... 更多 API
}

// 扩展上下文
interface ExtensionContext {
  session: AgentSession;
  settings: SettingsManager;
  // ... 更多上下文
}

// 事件类型 (部分)
interface AgentStartEvent {
  type: "agent_start";
  sessionId: string;
}

interface TurnStartEvent {
  type: "turn_start";
  userMessage: string;
}

interface ToolCallEvent {
  type: "toolcall";
  toolCall: ToolCall;
}

interface ToolCallEventResult {
  handled: boolean;
  result?: ToolResult;
}

interface MessageEndEvent {
  type: "message_end";
  message: AssistantMessage;
}
```

## 类型转换关系图

```
User Input (string)
    │
    ▼
UserMessage (pi-agent-core)
    │
    ▼
SessionEntry (SessionMessageEntry) ──▶ 持久化到文件
    │
    ▼
buildSessionContext() ──▶ AgentMessage[]
    │
    ▼
Agent.prompt() ──▶ AssistantMessage
    │
    ▼
ToolCall ──▶ ToolDefinition.execute() ──▶ ToolResult
    │
    ▼
ToolResultMessage ──▶ SessionEntry
```
