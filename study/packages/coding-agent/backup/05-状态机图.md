# Coding Agent 状态机图

## 1. Agent 会话状态机

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                              Agent 会话生命周期                                   │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                  │
│    ┌───────────────┐                                                            │
│    │   INITIAL     │ ←── 初始化中                                               │
│    │  (transient)  │                                                            │
│    └───────┬───────┘                                                            │
│            │ ResourceLoader.reload()                                             │
│            ▼                                                                     │
│    ┌───────────────┐                                                            │
│    │     IDLE      │ ←── 空闲，等待用户输入                                      │
│    │               │     • 可接受新消息                                          │
│    │               │     • 可切换模型                                            │
│    │               │     • 可执行 /commands                                      │
│    └───────┬───────┘                                                            │
│            │ prompt() / user input                                               │
│            ▼                                                                     │
│    ┌───────────────┐     ┌───────────────┐                                     │
│    │   STREAMING   │────→│  TOOL_CALLS   │                                     │
│    │               │     │               │                                     │
│    │ 接收 LLM      │←────│ 执行工具调用   │                                     │
│    │ 流式响应      │     │               │                                     │
│    │               │     │ • 并行执行     │                                     │
│    │ • text_delta  │     │ • 扩展拦截     │                                     │
│    │ • tool_use    │     │ • 结果收集     │                                     │
│    └───────────────┘     └───────────────┘                                     │
│            │                                                                     │
│            │ message_end (无 tool_calls)                                         │
│            ▼                                                                     │
│    ┌───────────────┐                                                            │
│    │  COMPLETING   │ ←── 完成处理                                               │
│    │               │     • 保存会话                                             │
│    │               │     • 检查压缩                                             │
│    │               │     • 触发事件                                             │
│    └───────┬───────┘                                                            │
│            │                                                                     │
│            └─────────────────────────────────────┐                              │
│                                                  │                              │
│    ┌─────────────────────────────────────────────┘                              │
│    │                                                                             │
│    ▼                                                                             │
│    ┌───────────────┐                                                            │
│    │   COMPACTING  │ ←── 压缩会话 (可能阻塞)                                     │
│    │               │     • 生成摘要                                             │
│    │               │     • 替换旧消息                                           │
│    │               │     • 保存压缩条目                                         │
│    └───────┬───────┘                                                            │
│            │ 完成                                                                 │
│            ▼                                                                     │
│    ┌───────────────┐                                                            │
│    │    DONE       │ ←── 回合完成                                               │
│    │               │     • 回到 IDLE                                            │
│    │               │     • 或继续（如有 steering/follow-up）                    │
│    └───────────────┘                                                            │
│            │                                                                     │
│            └────────────────────────────────────────────────────────────────┐   │
│                                                                              │   │
│    ╔═══════════════╗    ╔═══════════════╗    ╔═══════════════╗              │   │
│    ║   ABORTED     ║    ║   RETRYING    ║    ║    ERROR      ║              │   │
│    ║               ║    ║               ║    ║               ║              │   │
│    ║ 用户中断 (Esc) ║    ║ 自动重试中     ║    ║ 错误状态      ║              │   │
│    ║               ║    ║ • API 错误     ║    ║ • 保存错误    ║              │   │
│    ║ 清理资源      ║    ║ • 网络问题     ║    ║ • 扩展错误    ║              │   │
│    ╚═══════╤═══════╝    ╚═══════╤═══════╝    ╚═══════╤═══════╝              │   │
│            │                    │                    │                       │   │
│            └────────────────────┴────────────────────┘                       │   │
│                              │                                                │   │
│                              ▼                                                │   │
│                      ┌───────────────┐                                        │   │
│                      │     IDLE      │ ←── 恢复                               │   │
│                      └───────────────┘                                        │   │
│                                                                                  │
└─────────────────────────────────────────────────────────────────────────────────┘
```

│                              消息队列状态                                         │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                  │
│    ┌───────────────┐                                                            │
│    │   EMPTY       │ ←── 无排队消息                                             │
│    │               │                                                            │
│    └───────┬───────┘                                                            │
│            │ Enter (用户提交)                                                     │
│            │ Alt+Enter (follow-up)                                               │

│    ┌───────────────┐                                                            │
│    │   QUEUED      │ ←── 消息已排队                                             │
│    │               │     • steering: 下一回合交付                                │
│    │               │     • followUp: 所有工作完成后交付                          │
│    └───────┬───────┘                                                            │
│            │ Agent 完成回合                                                      │
│            ▼                                                                     │
│    ┌───────────────┐                                                            │
│    │  DELIVERING   │ ←── 正在交付消息                                           │
│    │               │     • 从队列移除                                           │
│    │               │     •
