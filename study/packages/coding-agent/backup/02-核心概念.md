# Coding Agent 核心概念

## 1. 领域术语表

| 术语 | 英文 | 含义 | 代码位置 |
|------|------|------|----------|
| 会话 | Session | 用户与 Agent 的完整对话历史 | `SessionManager`, JSONL 文件 |
| 分支 | Branch | 会话的树形分支结构，支持多版本 | `session.branch`, `/tree` |
| 分叉 | Fork | 从某点创建新会话副本 | `/fork`, `--fork` |
| 压缩 | Compaction | 自动/手动总结旧消息以节省上下文 | `core/compaction/` |
| 扩展 | Extension | TypeScript 模块，可注册工具/命令/UI | `core/extensions/` |
| 技能 | Skill | 按需加载的能力包（Markdown） | `core/skills.ts` |
| 提示模板 | Prompt Template | 可复用的提示词模板 | `core/prompt-templates.ts` |
| 模式 | Mode | 运行模式：interactive/print/rpc/sdk | `modes/` |
| 作用域模型 | Scoped Models | Ctrl+P 循环切换的模型列表 | `--models` |
| 思考等级 | Thinking Level | 模型推理强度：off/minimal/low/medium/high/xhigh | `ThinkingLevel` |

## 2. 核心抽象详解

### 2.1 AgentSession - 会话主控制器

**定位**: 桥接底层 Agent 框架与各运行模式的中间层

**职责**:
- 管理 Agent 生命周期（创建、运行、销毁）
- 事件订阅与转发（给 Extensions）
- 模型切换与思考等级管理
- 自动/手动会话压缩
- Bash 执行封装
- 会话分支与分叉

**关键方法**:
```typescript
// sdk.ts:153
async function createAgentSession(options: CreateAgentSessionOptions): Promise<CreateAgentSessionResult>

// agent-session.ts:395
class AgentSession {
  constructor(config: AgentSessionConfig)
  
  // 发送消息给 Agent
  async prompt(text: string, options?: PromptOptions): Promise<void>
  
  // 切换模型
  async setModel(model: Model<any>): Promise<void>
  
  // 设置思考等级
  setThinkingLevel(level: ThinkingLevel): void
  
  // 手动压缩
  async compact(options?: CompactOptions): Promise<CompactionResult | undefined>
  
  // 订阅事件
  subscribe(listener: AgentSessionEventListener): () => void
}
```

**内部状态**:

### 2.2 SessionManager - 会话持久化

**定位**: 负责会话的存储、加载、分支管理

**存储格式**: JSONL (JSON Lines)，每行一个 Entry

**Entry 类型**:
| 类型 | 用途 |
|------|------|
| `message` | 用户/助手消息 |
| `tool_call` | 工具调用 |
| `tool_result` | 工具执行结果 |
| `compaction` | 压缩摘要 |
| `branch_summary` | 分支摘要 |
| `model_change` | 模型切换记录 |
| `thinking_level_change` | 思考等级变更 |
| `custom` | 自定义条目 |

**树形结构**:
```typescript
// session-manager.ts
interface SessionEntryBase {
  id: string
  parentId: string | null  // ← 树形关系
  timestamp: number
  type: string
}
```

### 2.3 Extension System - 扩展系统

**设计理念**: Pi " aggressively extensible " - 核心最小，功能通过扩展实现

**Extension 可以做什么**:
1. **注册工具** - LLM 可调用的函数
2. **注册命令** - `/command` 斜杠命令
3. **注册快捷键** - 键盘绑定
4. **订阅事件** - Agent 生命周期钩子
5. **自定义 UI** - 替换编辑器、页脚、头部
6. **拦截工具调用** - 权限控制、日志记录

**事件类型**:
```typescript
// extensions/types.ts
type ExtensionEvent =
  | { type: "agent_start" }
  | { type: "agent_end" }
  | { type: "turn_start" }
  | { type: "turn_end" }

  | { type: "message_update" }
  | { type: "message_end" }
  | { type: "tool_call" }
  | { type: "tool_result" }
  | { type: "session_before_compact" }
  | { type: "session_compact" }
  | { type: "session_fork" }
  | ... // 更多
```

**Extension API**:

### 2.4 ResourceLoader - 资源加载器

**定位**: 统一发现并加载 extensions、skills、themes、prompts

**发现路径** (按优先级):
1. CLI 参数 (`--extension`, `--skill`, `--theme`)
2. 项目本地 (`.pi/`, `.agents/`)
3. 用户全局 (`~/.pi/agent/`)
4. Pi Packages (npm/git 安装的包)

**加载流程**:
```
ResourceLoader.reload()
  ↓
discoverExtensions() → loadExtensions()
discoverSkills()     → loadSkills()
discoverThemes()     → loadThemes()
discoverPrompts()    → loadPromptTemplates()
  ↓
ExtensionRunner.loadExtensions()
```

### 2.5 ModelRegistry - 模型注册表

**定位**: 管理所有可用模型及其认证

**功能**:
- 内置 Provider 模型列表 (`models.json`)
- 自定义 Provider 注册
- API Key 解析（环境变量、auth.json、OAuth）
- 模型能力检测（streaming、thinking、vision）

**模型标识**:
```typescript
// pi-ai 中的 Model 类型
interface Model<T> {
  provider: string      // e.g. "anthropic", "openai"
  id: string            // e.g. "claude-sonnet-4"
  name: string          // 显示名称
  reasoning?: boolean   // 是否支持思考
  vision?: boolean      // 是否支持视觉
  // ...
}
```

## 7. 压缩机制 (Compaction)

**触发条件**:
1. **阈值触发**: 上下文使用接近限制 (默认 80%)
2. **溢出触发**: LLM 返回 context overflow 错误
3. **手动触发**: `/compact` 命令

**压缩策略**:
```typescript
// compaction/compaction.ts
// 1. 找出切割点 (保留最近的 N 条消息)
// 2. 对旧消息生成摘要
// 3. 替换为 compaction entry
```

**压缩后结构**:
```
[旧消息] → [compaction: 摘要] → [保留的最近消息]
```
