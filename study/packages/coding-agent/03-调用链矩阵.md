# coding-agent 调用链矩阵

## 调用链 1: AgentSession.prompt()

### 完整调用路径

```
agentSession.prompt(userMessage, options)
    │
    ├──▶ buildSystemPrompt(cwd, skills, config)  [构建系统提示]
    │
    ├──▶ expandPromptTemplate(userMessage)       [展开提示模板]
    │
    ├──▶ createUserMessage(text, images)         [创建用户消息]
    │       └─▶ SessionManager.appendEntry("message")
    │
    ├──▶ emit("turn_start")                       [触发事件]
    │
    ├──▶ shouldCompact(context)                   [检查是否需要压缩]
    │       ├─▶ calculateContextTokens()
    │       └─▶ 如果超限: this.compact("overflow")
    │
    ├──▶ agent.prompt(systemPrompt, context)      [调用 pi-agent-core]
    │       │
    │       └─▶ [Agent.runLoop 内部]
    │           ├─▶ stream(model, context)
    │           ├─▶ 处理工具调用
    │           └─▶ 返回 AssistantMessage
    │
    ├──▶ 处理工具调用结果
    │       └─▶ executeToolCalls(toolCalls)
    │           ├─▶ emit("toolcall_start")
    │           ├─▶ tool.execute(input)
    │           └─▶ emit("toolcall_end")
    │
    ├──▶ SessionManager.appendEntry("message")   [持久化助手消息]
    │
    └──▶ emit("turn_end")
```

### 代码追踪

| 调用栈 | 代码/事件 | 类型/结构定义 | 疑问 & 答案 |
|--------|-----------|---------------|-------------|
| User 调用 | `agentSession.prompt("hello")` | `agent-session.ts` | - |
| └─> `buildSystemPrompt(cwd, skills, config)` | `system-prompt.ts` | `string` | Q: 系统提示包含什么？ |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> 读取 skills | `skills.ts` | `Skill[]` | A: 激活的 skills |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> 读取默认 prompt | `prompt-templates.ts` | `PromptTemplate` | A: 基础系统提示 |
| └─> `expandPromptTemplate(text)` | `prompt-templates.ts` | - | Q: 模板如何展开？ |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> `@file:path` 语法 | 正则匹配 | - | A: 嵌入文件内容 |
| └─> `sessionManager.appendEntry({type:"message",...})` | `session-manager.ts` | `SessionMessageEntry` | Q: 如何持久化？ |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> `fs.appendFileSync(sessionFile, json + "\\n")` | Node.js fs | - | A: JSON Lines 格式 |
| └─> `shouldCompact(context)` | `compaction/index.ts` | `boolean` | Q: 何时压缩？ |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> `calculateContextTokens()` | `compaction/calculate-tokens.ts` | `number` | A: 估算 token 数 |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> 比较阈值 | - | `compactThreshold` | A: 超过阈值触发 |
| └─> `agent.prompt(systemPrompt, messages, tools)` | `pi-agent-core` | `Agent` | - |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> `Agent.runLoop()` | `pi-agent-core` | - | Q: Agent 内部如何工作？ |
| └─> 工具调用处理 | `agent-session.ts:executeToolCalls` | `ToolCall[]` | - |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> 查找工具定义 | `ToolDefinition` | - | A: 从 registry 查找 |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> `tool.execute(input, context)` | - | `Promise<ToolResult>` | A: 执行实际逻辑 |
| 返回 | `void` (异步) | - | A: 通过事件通知 |

## 调用链 2: 工具执行 (bash tool)

### 调用路径

```
ToolCall 触发
    │
    ├──▶ AgentSession.executeToolCalls(toolCalls)
    │       │
    │       ├──▶ emit("toolcall_start", { toolCall })
    │       │
    │       ├──▶ findToolDefinition(toolCall.name)
    │       │       └─▶ 从 extensionRunner.tools 查找
    │       │
    │       ├──▶ validateToolInput(schema, args)  [AJV 验证]
    │       │
    │       ├──▶ emit("tool_execution_start")
    │       │
    │       ├──▶ tool.execute(input, context)
    │       │       │
    │       │       └─▶ [以 bash 为例]
    │       │           ├─▶ executeBashWithOperations(command, cwd)
    │       │           ├─▶ spawn shell process
    │       │           ├─▶ capture stdout/stderr
    │       │           └─▶ return { stdout, stderr, exitCode }
    │       │
    │       ├──▶ emit("tool_execution_update")  [流式输出]
    │       │
    │       ├──▶ emit("tool_execution_end")
    │       │
    │       ├──▶ createToolResultMessage(result)
    │       │       └─▶ SessionManager.appendEntry("message")
    │       │
    │       └──▶ emit("toolcall_end")
    │
    └──▶ 继续 Agent 循环 (如果有更多工具调用)
```

| &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;└─> `spawn("bash", ["-c", command])` | Node.js child_process | - | A: 子进程 |

## 调用链 3: 会话压缩 (Compaction)

### 调用路径

```
shouldCompact(context) 返回 true
    │
    ├──▶ AgentSession.compact(reason)
    │       │
    │       ├──▶ emit("compaction_start", { reason })
    │       │
    │       ├──▶ prepareCompaction(context, settings)
    │       │       │
    │       │       ├──▶ findCutPoint(entries, threshold)
    │       │       │       └─▶ 找到 token 累计超过阈值的点
    │       │       │
    │       │       ├──▶ collectEntriesForBranchSummary(...)
    │       │       │       └─▶ 收集切割点之前的 entries
    │       │       │
    │       │       └──▶ prepareBranchEntries(entriesToSummarize)
    │       │               └─▶ 序列化为对话格式
    │       │
    │       ├──▶ generateBranchSummary(options)
    │       │       │
    │       │       ├──▶ buildPromptForSummary(branchEntries)
    │       │       │       └─▶ 构建"请总结这段对话"提示
    │       │       │
    │       │       ├──▶ stream(model, summaryPrompt)
    │       │       │       └─▶ 调用 LLM 生成摘要
    │       │       │
    │       │       └──▶ 返回 summaryText
    │       │
    │       ├──▶ createCompactionEntry(summary, firstKeptId, tokens)
    │       │       └─▶ SessionManager.appendEntry({type:"compaction",...})
    │       │
    │       ├──▶ removeOldEntriesBefore(cutPoint)
    │       │       └─▶ 截断会话文件 (保留 compaction 后的 entries)
    │       │
    │       └──▶ emit("compaction_end", { result, aborted: false })
```

### 代码追踪

| 调用栈 | 代码/事件 | 类型/结构定义 | 疑问 & 答案 |

| &nbsp;&nbsp;&nbsp;&nbsp;└─> `/compact` 命令 | `slash-commands.ts` | - | A: 可以 |
| └─> `prepareCompaction(...)` | `compaction/index.ts` | `PrepareCompactionResult` | - |
