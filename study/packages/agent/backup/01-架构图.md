## 入口点

| 入口 | 文件 | 用途 |
|------|------|------|
| `Agent` 类 | `agent.ts` | 高层封装，推荐使用 |
| `agentLoop()` | `agent-loop.ts` | 低层 API，直接控制 |
| `agentLoopContinue()` | `agent-loop.ts` | 低层继续 API |

## 关键设计模式

1. **事件驱动**: 所有状态变化通过 `AgentEvent` 通知订阅者
2. **状态机**: `isStreaming` / `streamMessage` 等状态控制流程
3. **队列模式**: `steeringQueue` / `followUpQueue` 支持异步干预
4. **流式处理**: LLM 响应通过 `message_update` 事件流式传递
5. **工具钩子**: `beforeToolCall` / `afterToolCall` 支持拦截和修改
