# agent 类型手册

## 核心类型速查表

### Agent 类

| 属性/方法 | 类型 | 说明 |
|-----------|------|------|
| `state` | `AgentState` | 当前状态 (只读) |
| `sessionId` | `string \| undefined` | 会话 ID |
| `thinkingBudgets` | `ThinkingBudgets \| undefined` | 推理预算 |
| `prompt(message)` | `Promise<void>` | 发送消息 |
| `setModel(model)` | `void` | 设置模型 |
| `setSystemPrompt(prompt)` | `void` | 设置系统提示 |
| `addTool(tool)` | `void` | 添加工具 |
| `addListener(fn)` | `void` | 添加事件监听 |
| `removeListener(fn)` | `void` | 移除事件监听 |

interface AgentState {

### AgentTool

```typescript
interface AgentTool<TParameters extends TSchema = TSchema, TDetails = any> 
  extends Tool<TParameters> {
  label: string;
  execute: (
    toolCallId: string,
    params: Static<TParameters>,
    signal?: AbortSignal,
    onUpdate?: AgentToolUpdateCallback<TDetails>,
  ) => Promise<AgentToolResult<TDetails>>;
}
```

**示例**：
```typescript
const myTool: AgentTool = {
  name: "my_tool",
  description: "Does something",
  label: "My Tool",
  parameters: Type.Object({ input: Type.String() }),
  execute: async (toolCallId, params, signal, onUpdate) => {
    return {
      content: [{ type: "text", text: "Result" }],
      details: { extra: "data" }
    };
  }
};
```

### AgentEvent

```typescript
type AgentEvent =
  | { type: "agent_start" }
  | { type: "agent_end"; messages: AgentMessage[] }

  | { type: "tool_execution_update"; toolCallId: string; toolName: string; args: any; partialResult: any }
  | { type: "tool_execution_end"; toolCallId: string; toolName: string; result: any; isError: boolean };
```

### Tool Execution Hooks

```typescript
interface BeforeToolCallContext {
  assistantMessage: AssistantMessage;
  toolCall: AgentToolCall;
  args: unknown;
  context: AgentContext;
}

interface BeforeToolCallResult {
  block?: boolean;
  reason?: string;
}

type BeforeToolCallHook = (
  context: BeforeToolCallContext,
  signal?: AbortSignal
) => Promise<BeforeToolCallResult | undefined>;

interface AfterToolCallContext {
  assistantMessage: AssistantMessage;
  toolCall: AgentToolCall;
  args: unknown;
  result: AgentToolResult<any>;
  isError: boolean;
  context: AgentContext;
}

interface AfterToolCallResult {
  content?: (TextContent | ImageContent)[];
  details?: unknown;
  isError?: boolean;
}

type AfterToolCallHook = (
  context: AfterToolCallContext,
  signal?: AbortSignal
) => Promise<AfterToolCallResult | undefined>;
```

## 类型关系图

```
Agent
    │
    ├──▶ AgentState
    │       ├──▶ messages: AgentMessage[]
    │       ├──▶ tools: AgentTool[]
    │       └──▶ model: Model
    │
    ├──▶ AgentOptions
    │       ├──▶ convertToLlm: (AgentMessage[]) => Message[]
    │       ├──▶ transformContext: (AgentMessage[]) => AgentMessage[]
    │       ├──▶ beforeToolCall: Hook
    │       └──▶ afterToolCall: Hook
    │
    └──▶ EventStream<AgentEvent, AgentMessage[]>
            │
            ├──▶ AgentEvent
            │       ├──▶ agent_start / agent_end
            │       ├──▶ turn_start / turn_end
            │       ├──▶ message_start / update / end
            │       └──▶ tool_execution_start / update / end
            │
            └──▶ AgentMessage[] (结果)

AgentLoop (函数)
    │
    ├──▶ AgentLoopConfig
    │       ├──▶ model: Model
    │       ├──▶ convertToLlm
    │       ├──▶ getSteeringMessages
    │       └──▶ getFollowUpMessages
    │
    └──▶ EventStream<AgentEvent, AgentMessage[]>
```
