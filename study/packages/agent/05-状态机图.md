## 6. 状态转换表

### Agent 状态转换

| 当前状态 | 事件 | 下一个状态 | 说明 |
|----------|------|------------|------|
| IDLE | `prompt()` | RUNNING | 开始运行 |
| RUNNING | `streamSimple` 开始 | STREAMING | 接收 LLM 响应 |
| STREAMING | 有 tool calls | EXECUTING | 执行工具 |
| EXECUTING | 工具完成 | PENDING | 等待 steering |
| PENDING | `setSteeringMessages` | RUNNING | 继续运行 |
| PENDING | 无 steering, 有 followUp | RUNNING | 继续运行 |
| PENDING | 无 steering, 无 followUp | IDLE | 回到空闲 |
| * | `reset()` | IDLE | 强制重置 |
| * | 错误 | ERROR | 错误状态 |

### Loop 状态转换

| 当前状态 | 事件 | 下一个状态 | 说明 |
|----------|------|------------|------|
| - | 调用 `agentLoop()` | AGENT_START | 开始 |
| AGENT_START | - | TURN_START | 回合开始 |
| TURN_START | 有 pending messages | PROCESS_PENDING | 处理 steering |
| PROCESS_PENDING | - | STREAMING | 调用 LLM |
| STREAMING | 有 tool calls | EXECUTING | 执行工具 |
| STREAMING | 无 tool calls | TURN_END | 回合结束 |
| EXECUTING | 完成 | TURN_END | 回合结束 |
| TURN_END | 有 steering | TURN_START | 继续回合 |
| TURN_END | 无 steering, 有 followUp | TURN_START | 新回合 |
| TURN_END | 无 steering, 无 followUp | AGENT_END | 结束 |
| AGENT_END | - | - | 完成 |
