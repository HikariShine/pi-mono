# pi-agent-core 状态机图

## isStreaming 状态机

```
                    ┌─────────────────────────────────────┐
                    │                                     │
                    ▼                                     │
┌──────────┐   prompt()   ┌──────────┐   完成/错误   ┌──────────┐
│   IDLE   │ ───────────► │ STREAMING│ ───────────► │   IDLE   │
│ (false)  │              │  (true)  │              │ (false)  │
└──────────┘              └────┬─────┘              └──────────┘
                               │
                               │ abort()
                               ▼
                         ┌──────────┐
                         │ ABORTED  │
                         └──────────┘
```

### 状态变更时机

| 事件 | 当前状态 | 新状态 | 触发代码 |
|------|----------|--------|----------|
| `prompt()` / `continue()` | `false` | `true` | `_runLoop(): this._state.isStreaming = true` |
| 正常完成 | `true` | `false` | `finally: this._state.isStreaming = false` |
| 出错 | `true` | `false` | `catch: emit agent_end with error` |
| `abort()` | `true` | `false` | `this.abortController?.abort()` → 触发 signal → 退出循环 |

## streamMessage 状态机

```
┌─────────┐              ┌─────────────┐              ┌─────────┐
│  null   │ ──LLM start──►│ {partial}   │ ──LLM end───►│  null   │
└─────────┘              └──────┬──────┘              └─────────┘
                                │
                                │ text_delta / toolcall_delta
                                ▼
                         ┌─────────────┐
                         │ {updated}   │
                         └─────────────┘
                                │
                                │ (循环直到 done/error)
                                ▼
                         ┌─────────────┐
                         │ {final}     │
                         └─────────────┘
```

### 状态变更时机

| 事件 | 旧值 | 新值 | 触发代码 |
|------|------|------|----------|
| `message_start` | `null` | `partialMessage` | `streamAssistantResponse(): context.messages.push(partial)` |
| `message_update` | `partial` | `updatedPartial` | `context.messages[...] = partialMessage` |
| `message_end` | `final` | `null` | `_processLoopEvent(): this._state.streamMessage = null` |

## pendingToolCalls 状态机

```
┌─────────────┐     tool_execution_start     ┌─────────────┐
│   Set()     │ ─────────────────────────────►│  Set(id1)   │
│   (empty)   │                               │             │
└─────────────┘                               └──────┬──────┘
                                                     │
                                                     │ tool_execution_start
                                                     │ (并行执行多个)
                                                     ▼
                                              ┌─────────────┐
                                              │ Set(id1,id2)│
                                              └──────┬──────┘
                                                     │
                                                     │ tool_execution_end
                                                     ▼
                                              ┌─────────────┐
                                              │   Set(id2)  │
                                              └──────┬──────┘
                                                     │
                                                     │ tool_execution_end
                                                     ▼
                                              ┌─────────────┐
                                              │   Set()     │
                                              │  (empty)    │
                                              └─────────────┘
```

### 状态变更时机

| 事件 | 操作 | 代码 |
|------|------|------|
| `tool_execution_start` | `add(toolCallId)` | `pendingToolCalls.add(event.toolCallId)` |
| `tool_execution_end` | `delete(toolCallId)` | `pendingToolCalls.delete(event.toolCallId)` |
| `reset()` / 新会话 | `clear()` | `new Set<string>()` |

## Agent 生命周期状态机

```
┌───────────┐
│  CREATED  │ ◄── new Agent()
└─────┬─────┘
      │ prompt() / continue()
      ▼
┌───────────┐     tool calls      ┌───────────┐
│ RUNNING   │ ───────────────────►│ RUNNING   │
│ (turn 1)  │ ◄───────────────────│ (turn 2)  │
└─────┬─────┘     tool results    └─────┬─────┘
      │                                 │
      │ steering/follow-up              │ steering/follow-up
      ▼                                 ▼
┌───────────┐                       ┌───────────┐
│ RUNNING   │                       │ RUNNING   │
│ (turn N)  │                       │ (turn N)  │
└─────┬─────┘                       └─────┬─────┘
      │                                   │
      │ 无 steering/follow-up，无 tools   │
      ▼                                   ▼
┌───────────┐                       ┌───────────┐
│   IDLE    │                       │   IDLE    │
└───────────┘                       └───────────┘
      │                                   │
      │ abort()                           │ error
      ▼                                   ▼
┌───────────┐                       ┌───────────┐
│  ABORTED  │                       │  ERROR    │
└───────────┘                       └───────────┘
```

```
│          │                                                          │

│          ▼                                                          │
│   ┌─────────────┐                                                   │

│          ▼                                                          │

│   │   IDLE      │ ◄── 回到初始状态                                  │

```

## 队列状态机

### Steering Queue

```
┌───────────┐     steer(msg)     ┌───────────┐
│   empty   │ ─────────────────► │  [msg]    │
└───────────┘                    └─────┬─────┘
                                       │
                                       │ steer(msg2)
                                       ▼
                                ┌───────────┐
                                │ [msg,msg2]│
                                └─────┬─────┘
                                      │
                                      │ 回合结束
                                      │ dequeueSteeringMessages()
                                      ▼
                                ┌───────────┐
                                │   empty   │ (消息已注入)
                                └───────────┘
```

### Follow-up Queue

```
┌───────────┐     followUp(msg)  ┌───────────┐
│   empty   │ ─────────────────► │  [msg]    │
└───────────┘                    └─────┬─────┘
                                       │
                                       │ 无 tools/steering
                                       │ dequeueFollowUpMessages()
                                       ▼
                                ┌───────────┐
                                │   empty   │ (消息已注入)
                                └───────────┘
```

## 状态一致性检查点

| 检查点 | 预期状态 |
|--------|----------|
| `prompt()` 开始前 | `isStreaming === false` |
| `_runLoop()` 开始时 | `isStreaming === true`, `streamMessage === null` |
| `streamAssistantResponse()` 开始时 | `streamMessage === null` |
| `message_start` 后 | `streamMessage !== null` |
| `message_end` 后 | `streamMessage === null` |
| `tool_execution_start` 后 | `pendingToolCalls.has(id) === true` |
| `tool_execution_end` 后 | `pendingToolCalls.has(id) === false` |
| `agent_end` 时 | `isStreaming === false`, `streamMessage === null`, `pendingToolCalls.size === 0` |
