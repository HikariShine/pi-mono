# agent (pi-agent-core) 架构图

## 项目概述

**pi-agent-core** 是一个通用的 Agent 核心库，提供：
- Agent 状态管理
- 与 LLM 的交互循环 (Agent Loop)
- 工具调用执行 (顺序/并行)
- 消息转换和上下文管理
- 代理服务器支持 (Proxy)

这是 coding-agent 的底层依赖，负责最核心的 Agent 循环逻辑。

## 核心组件职责

| 组件 | 文件 | 职责 |
|------|------|------|
| **Agent** | `agent.ts` | 高级封装类，管理 Agent 状态和生命周期，提供 steering/followUp 机制 |
| **agentLoop** | `agent-loop.ts` | 核心循环函数，处理 LLM 调用、工具执行、事件发射 |
| **streamProxy** | `proxy.ts` | 代理服务器流函数，用于通过后端中转 LLM 调用 |
| **Types** | `types.ts` | 所有类型定义 (AgentState, AgentTool, AgentEvent, etc.) |

## 数据流架构

```
User Input (AgentMessage)
    │
    ▼
┌───────────────────────────────────────────────┐
│           Agent.prompt(message)               │
│                                               │
│  ┌─────────────────────────────────────────┐  │
│  │ 1. 添加到消息队列                       │  │
│  │ 2. 启动 Agent Loop (如果未运行)         │  │
│  │ 3. 等待 Loop 完成                       │  │
│  └─────────────────────────────────────────┘  │
└───────────────────┬───────────────────────────┘
                    │
                    ▼
┌───────────────────────────────────────────────┐
│              agentLoop()                        │
│                                               │
│  ┌─────────────────────────────────────────┐  │
│  │ Outer Loop:                             │  │
│  │ - 处理 steering messages                │  │
│  │ - 处理 follow-up messages               │  │
│  │ - 检查终止条件                          │  │
│  └─────────────────────────────────────────┘  │
│                    │                          │
│                    ▼                          │
│  ┌─────────────────────────────────────────┐  │
│  │ Inner Loop (per turn):                  │  │
│  │ - transformContext()                    │  │
│  │ - convertToLlm() → Message[]            │  │
│  │ - streamSimple() → AssistantMessage     │  │
│  │ - 如果有 tool calls:                    │  │
│  │   - beforeToolCall() hook               │  │
│  │   - executeToolCalls()                  │  │
│  │   - afterToolCall() hook                │  │
│  │   - 添加 ToolResult 到 context          │  │
│  │ - 发射 turn_end 事件                    │  │
│  └─────────────────────────────────────────┘  │
│                    │                          │
└────────────────────┼──────────────────────────┘
                     │
                     ▼
┌───────────────────────────────────────────────┐
│              EventStream                        │
│                                               │
│  - agent_start                                │
│  - turn_start                                 │
│  - message_start / message_update / message_end│
│  - tool_execution_start / _update / _end      │
│  - turn_end                                   │
│  - agent_end                                  │
└───────────────────────────────────────────────┘
```

## 与 pi-ai 的关系

```
pi-agent-core (本模块)
    │
    ├──▶ 依赖 pi-ai 的 streamSimple() 进行 LLM 调用
    │
    ├──▶ 依赖 pi-ai 的 EventStream 进行事件流管理
    │
    ├──▶ 依赖 pi-ai 的 validateToolArguments() 验证工具参数
    │
    └──▶ 复用 pi-ai 的类型 (AssistantMessage, Context, Tool, etc.)

扩展点:
- convertToLlm: AgentMessage[] → Message[] (过滤/转换)
- transformContext: AgentMessage[] → AgentMessage[] (上下文管理)
- beforeToolCall / afterToolCall: 工具调用钩子
```

## 与 coding-agent 的关系

```
coding-agent (上层应用)
    │
    ├──▶ 使用 pi-agent-core 的 Agent 类
    │
    ├──▶ 提供 AgentSession 封装 (会话持久化、UI 等)
    │
    ├──▶ 实现工具 (read, bash, edit, write, etc.)
    │
    └──▶ 实现 convertToLlm (过滤非 LLM 消息)

pi-agent-core 提供:
- 核心 Agent 循环
- 工具执行框架
- 事件系统
- 状态管理
```
