# agent 核心概念

## 1. Agent 类

### 1.1 职责

`Agent` 类是 pi-agent-core 的高级封装，提供：
- Agent 状态管理
- 事件订阅/发布
- Steering/FollowUp 消息队列
- Prompt 接口 (同步/异步)

### 1.2 状态 (AgentState)

```typescript
interface AgentState {
  systemPrompt: string;           // 系统提示词
  model: Model<any>;              // 当前模型
  thinkingLevel: ThinkingLevel;   // 推理级别
  tools: AgentTool<any>[];        // 可用工具
  messages: AgentMessage[];       // 对话历史
  isStreaming: boolean;           // 是否正在流式响应
  streamMessage: AgentMessage | null;  // 当前流式消息
  pendingToolCalls: Set<string>;  // 待执行的 tool call IDs
  error?: string;                 // 错误信息
}
```

### 1.3 Steering / FollowUp 机制

```typescript
// Steering: 用户可以在 Agent 工作时"干预"
// 例如：在 TUI 中用户输入新消息，立即发送
agent.setSteeringMessages([userMessage]);

// FollowUp: Agent 完成后自动继续的消息
// 例如：系统消息、自动跟进
agent.setFollowUpMessages([systemMessage]);
```

**工作方式**：
- `steeringMode`: `"all"` (一次性发送所有) 或 `"one-at-a-time"` (逐条)
- `followUpMode`: 同上

## 2. Agent Loop

### 2.1 双循环结构

```
Outer Loop (外层循环)
    │
    ├──▶ 处理 steering messages
    │
    ├──▶ 处理 follow-up messages
    │
    └──▶ 检查终止条件 → 退出

Inner Loop (内层循环 - 每轮对话)
    │
    ├──▶ transformContext() → 上下文变换
    │
    ├──▶ convertToLlm() → 转换为 LLM 格式
    │
    ├──▶ streamSimple() → 调用 LLM
    │
    ├──▶ 如果有 tool calls:
    │       │
    │       ├──▶ beforeToolCall() hook
    │       ├──▶ executeToolCalls()
    │       ├──▶ afterToolCall() hook
    │       └──▶ 添加结果到 context
    │
    └──▶ 检查 steering → 继续内层循环
```

### 2.2 Loop 函数

| 函数 | 用途 |
|------|------|
| `agentLoop()` | 启动新循环，添加 prompt 消息 |
| `agentLoopContinue()` | 继续现有循环，不添加新消息 |
| `runAgentLoop()` | 内部实现，返回 Promise |
| `runAgentLoopContinue()` | 内部实现，继续循环 |

## 3. 工具系统

### 3.1 AgentTool 接口

```typescript
interface AgentTool<TParameters extends TSchema = TSchema, TDetails = any> 
  extends Tool<TParameters> {
  label: string;  // 显示标签
  execute: (
    toolCallId: string,
    params: Static<TParameters>,
    signal?: AbortSignal,
    onUpdate?: AgentToolUpdateCallback<TDetails>,
  ) => Promise<AgentToolResult<TDetails>>;
}
```

### 3.2 工具执行模式

```typescript
type ToolExecutionMode = "sequential" | "parallel";

// sequential: 顺序执行 (准备 → 执行 → 完成) × N
// parallel: 并行执行 (准备) × N → (执行) × N (并发)
```

### 3.3 工具结果

```typescript
interface AgentToolResult<T> {
  content: (TextContent | ImageContent)[];  // 显示内容
```

### 4.2 convertToLlm

```typescript
type ConvertToLlm = (messages: AgentMessage[]) => Message[] | Promise<Message[]>;

// 默认实现: 过滤只保留 user/assistant/toolResult
function defaultConvertToLlm(messages: AgentMessage[]): Message[] {
  return messages.filter(m => 
    m.role === "user" || 
    m.role === "assistant" || 
    m.role === "toolResult"
  );
}
```

## 5. 事件系统

### 5.1 AgentEvent

```typescript
type AgentEvent =
  // Agent 生命周期
  | { type: "agent_start" }
  | { type: "agent_end"; messages: AgentMessage[] }
  
  // Turn 生命周期 (一轮对话)
  | { type: "turn_start" }
  | { type: "turn_end"; message: AgentMessage; toolResults: ToolResultMessage[] }
  
  // Message 生命周期
  | { type: "message_start"; message: AgentMessage }
  | { type: "message_update"; message: AgentMessage; assistantMessageEvent: AssistantMessageEvent }
  | { type: "message_end"; message: AgentMessage }
  
  // Tool 执行生命周期
  | { type: "tool_execution_start"; toolCallId: string; toolName: string; args: any }
  | { type: "tool_execution_update"; toolCallId: string; toolName: string; args: any; partialResult: any }
  | { type: "tool_execution_end"; toolCallId: string; toolName: string; result: any; isError: boolean };
```

### 5.2 EventStream

```typescript
import { EventStream } from "@mariozechner/pi-ai";

const stream = new EventStream<AgentEvent, AgentMessage[]>(
  (event) => event.type === "agent_end",           // 结束条件
  (event) => event.type === "agent_end" ? event.messages : []  // 提取结果
);

// 使用
for await (const event of stream) {
  console.log(event.type);
}

const messages = await stream.result();
```

## 6. 工具调用钩子

### 6.1 beforeToolCall

```typescript
interface BeforeToolCallResult {
  block?: boolean;      // 阻止执行
  reason?: string;      // 阻止原因
}

interface BeforeToolCallContext {
  assistantMessage: AssistantMessage;
  toolCall: AgentToolCall;
  args: unknown;        // 已验证的参数
  context: AgentContext;
}

// 示例: 阻止危险命令
const beforeToolCall = (ctx) => {
  if (ctx.toolCall.name === "bash" && 
      ctx.args.command.includes("rm -rf /")) {
    return { block: true, reason: "Dangerous command blocked" };
  }
};
```

### 6.2 afterToolCall

```typescript
interface AfterToolCallResult {
  content?: (TextContent | ImageContent)[];
  details?: unknown;
  isError?: boolean;
}

interface AfterToolCallContext {
  assistantMessage: AssistantMessage;
  toolCall: AgentToolCall;
  args: unknown;
  result: AgentToolResult<any>;
  isError: boolean;
  context: AgentContext;
}

// 示例: 修改结果
const afterToolCall = (ctx) => {
  return {
    content: [{ type: "text", text: "[Modified] " + ctx.result.content[0].text }]
  };
};
```

## 9. 与 coding-agent 的对比

| 功能 | pi-agent-core (本模块) | coding-agent (上层) |
|------|------------------------|---------------------|
| Agent 循环 | ✅ 核心实现 | 使用本模块 |
| 状态管理 | ✅ 基础状态 | 扩展 (会话持久化) |
| 工具定义 | ✅ 接口定义 | 具体实现 (read, bash, etc.) |
| 事件系统 | ✅ 基础事件 | 扩展 (UI 事件) |
| 会话持久化 | ❌ | ✅ SessionManager |
| 扩展系统 | ❌ | ✅ ExtensionRunner |
| TUI | ❌ | ✅ InteractiveMode |
| 压缩 | ❌ | ✅ Compaction |
