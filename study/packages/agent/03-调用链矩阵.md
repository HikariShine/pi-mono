# pi-agent-core 调用链矩阵

## 调用链 1: agent.prompt() → 标准对话流程

### 路径: `agent.prompt("Hello")` → 无 tool calls

| Stack | Code | Type Definition | Q&A |
|-------|------|-----------------|-----|
| `Agent.prompt()` | `if (isStreaming) throw` | `isStreaming: boolean` | Q: 为什么不能并发？<br>A: 设计为单会话串行，防止状态混乱 |
| | `let msgs: AgentMessage[]` | `AgentMessage: { role, content, timestamp }` | 构建用户消息 |
| └─> `_runLoop(msgs)` | `const model = this._state.model` | `Model<any>: { api, provider, id }` | 检查模型配置 |
| | `this.runningPrompt = new Promise(...)` | `runningPrompt?: Promise<void>` | 用于 waitForIdle() |
| | `this.abortController = new AbortController()` | `AbortController` | 支持取消操作 |
| | `this._state.isStreaming = true` | ⚠️ **状态变更** | isStreaming: false → true |
| | `context: AgentContext = { systemPrompt, messages, tools }` | `AgentContext: { systemPrompt, messages, tools }` | 浅拷贝当前状态 |
| └─> `runAgentLoop(prompts, context, config, emit, signal, streamFn)` | | | 进入循环 |
| | `newMessages: AgentMessage[] = [...prompts]` | | 本轮新增消息列表 |
| | `currentContext.messages = [...context.messages, ...prompts]` | ⚠️ **注意** | messages 是展开拷贝 |
| | `emit({ type: "agent_start" })` | `AgentEvent: { type: "agent_start" }` | 通知订阅者开始 |
| | `emit({ type: "turn_start" })` | `AgentEvent: { type: "turn_start" }` | 新回合开始 |
| | `for (const prompt of prompts)` | | 遍历用户消息 |
| | `emit({ type: "message_start", message: prompt })` | | 消息开始事件 |
| | `emit({ type: "message_end", message: prompt })` | | 消息结束事件 |
| └─> `runLoop(currentContext, newMessages, config, signal, emit, streamFn)` | | | 主循环 |
| | `firstTurn = true` | | 标记首回合 |
| | `pendingMessages = await config.getSteeringMessages?.() \|\| []` | `AgentMessage[]` | 检查 steering 队列 |
| | `while (true)` | | 外层循环：处理 follow-up |
| | `while (hasMoreToolCalls \|\| pendingMessages.length > 0)` | | 内层循环：处理 tools |
| | `emit({ type: "turn_start" })` | | 非首回合时触发 |

| | `llmMessages = await config.convertToLlm(messages)` | `convertToLlm: (msgs) => Message[]` | **必需**：转 LLM 格式 |
| | `llmContext: Context = { systemPrompt, messages, tools }` | `Context` (from pi-ai) | pi-ai 的上下文 |
| | `response = await streamFunction(model, llmContext, ...)` | `EventStream<AssistantMessageEvent, AssistantMessage>` | 流式响应 |
| | `for await (const event of response)` | | 处理流式事件 |
| | `case "start":` | | LLM 开始响应 |
| | `partialMessage = event.partial` | `AssistantMessage` | 创建 partial |
| | `context.messages.push(partialMessage)` | ⚠️ **状态变更** | 添加到上下文！ |
| | `addedPartial = true` | | 标记已添加 |
| | `emit({ type: "message_start", message: {...partial} })` | | 通知消息开始 |
| | `case "text_delta":` | | 收到文本增量 |
| | `partialMessage = event.partial` | | 更新 partial |
| | `context.messages[context.messages.length - 1] = partialMessage` | ⚠️ **更新最后一条** | 替换为最新 partial |
| | `emit({ type: "message_update", ... })` | | 通知更新 |
| | `case "done": / "error":` | | 流式结束 |
| | `finalMessage = await response.result()` | | 获取最终消息 |
| | `if (addedPartial) context.messages[...] = finalMessage` | | 替换 partial 为 final |
| | `else context.messages.push(finalMessage)` | | 直接添加 final |
| | `emit({ type: "message_end", message: finalMessage })` | | 通知消息结束 |
| | `return finalMessage` | | 返回完整消息 |
| (回到 runLoop) | `newMessages.push(message)` | | 记录到本轮新增 |
| | `if (stopReason === "error" \|\| "aborted")` | | 错误处理 |
| | `emit({ type: "turn_end", message, toolResults: [] })` | | 回合结束 |
| | `emit({ type: "agent_end", messages: newMessages })` | | Agent 结束 |
| | `return` | | 退出循环 |
| | `const toolCalls = message.content.filter(c => c.type === "toolCall")` | | 提取 tool calls |
| | `hasMoreToolCalls = toolCalls.length > 0` | | 检查是否有工具 |
| | `// 假设无 tool calls` | | 本场景：无工具 |
| | `hasMoreToolCalls = false` | | 跳出内层循环 |
| | `emit({ type: "turn_end", message, toolResults: [] })` | | 回合结束 |
| | `const followUpMessages = await config.getFollowUpMessages?.()` | | 检查 follow-up |
| | `if (followUpMessages.length > 0)` | | 有跟进消息？ |
| | `pendingMessages = followUpMessages; continue` | | 设置并继续外层循环 |
| | `break` | | 无 follow-up，退出 |
| (回到 runAgentLoop) | `return newMessages` | | 返回本轮新增 |
| (回到 _runLoop) | `// finally 块` | | |
| | `this._state.isStreaming = false` | ⚠️ **状态恢复** | isStreaming: true → false |
| | `this._state.streamMessage = null` | ⚠️ **状态恢复** | streamMessage: null |
| | `this._state.pendingToolCalls = new Set()` | ⚠️ **状态恢复** | 清空 pending |
| | `this.resolveRunningPrompt?.()` | | 通知等待者 |

## 调用链 2: agent.prompt() → 有 tool calls

### 路径: `agent.prompt("Read file")` → 触发 read 工具

| Stack | Code | Type Definition | Q&A |
|-------|------|-----------------|-----|
| (接调用链 1 到 streamAssistantResponse 返回) | `message` 包含 `toolCall` | `content: [{ type: "toolCall", id, name, arguments }]` | LLM 请求工具 |
| (回到 runLoop) | `hasMoreToolCalls = true` | | 标记有工具 |
| | `toolResults: ToolResultMessage[] = []` | | 准备结果容器 |
| | `emit({ type: "turn_end", message, toolResults: [] })` | | 注意：此时 toolResults 为空 |
| └─> `executeToolCalls(currentContext, message, config, signal, emit)` | | | 执行工具 |
| | `const toolCalls = assistantMessage.content.filter(...)` | `AgentToolCall[]` | 提取 tool calls |
| | `if (config.toolExecution === "sequential")` | `ToolExecutionMode` | 判断执行模式 |
| | `// 假设 "parallel"` | | 并行模式 |
| └─> `executeToolCallsParallel(...)` | | | 并行执行 |
| | `results: ToolResultMessage[] = []` | | |
| | `runnableCalls: PreparedToolCall[] = []` | | 准备执行的列表 |
| | `for (const toolCall of toolCalls)` | | 遍历 tool calls |
| | `emit({ type: "tool_execution_start", toolCallId, toolName, args })` | | 通知工具开始 |
| | `const preparation = await prepareToolCall(...)` | `PreparedToolCall \| ImmediateToolCallOutcome` | 准备工具 |
| | `if (preparation.kind === "immediate")` | | 立即可完成（如缓存）|
| | `results.push(await emitToolCallOutcome(...))` | | 直接添加结果 |
| | `else runnableCalls.push(preparation)` | | 加入待执行列表 |
| | `const runningCalls = runnableCalls.map(prepared => ({ prepared, execution: executePreparedToolCall(...) }))` | ⚠️ **关键** | 启动所有异步执行！ |
| | `// 此时所有工具已并行启动` | | |
| | `for (const running of runningCalls)` | | 按顺序等待结果 |
| | `const executed = await running.execution` | | 等待单个完成 |
| | `results.push(await finalizeExecutedToolCall(...))` | | 格式化结果 |
| | `return results` | | 返回所有结果 |
| (回到 runLoop) | `for (const result of toolResults)` | | 处理返回结果 |
| | `currentContext.messages.push(result)` | ⚠️ **关键** | 添加 toolResult 到上下文 |
| | `newMessages.push(result)` | | 记录到本轮新增 |
| | `emit({ type: "turn_end", message, toolResults })` | | 带结果的回合结束 |
| | `hasMoreToolCalls = false` | | 本轮工具完成 |
| | `// 继续循环...` | | 内层循环继续，LLM 会收到 toolResult |
| └─> `streamAssistantResponse(...)` | | | 再次调用 LLM |
| | `// context.messages 已包含 toolResult` | | LLM 看到工具结果 |
| | `// LLM 返回最终回复（无 tool calls）` | | |
| | `// 退出内层循环` | | |
| | `// 检查 follow-up...` | | |

**⚠️ 关键观察**：
1. `tool_execution_start` emit 后立即启动异步执行
2. `toolResult` 要等到 `executeToolCalls` 完成才添加到 `messages`
3. 执行期间 `messages` 只有 `assistant(toolCalls)`，没有 `toolResult`
4. 如果此时崩溃，恢复后 LLM 会看到
