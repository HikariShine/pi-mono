# agent 调用链矩阵

## 调用链 1: Agent.prompt()

### 完整调用路径

```
agent.prompt(userMessage)
    │
    ├──▶ this.enqueueSteeringMessage(userMessage)
    │       └─▶ 添加到 steeringQueue
    │
    ├──▶ 如果 loop 未运行: this.startAgentLoop()
    │       │
    │       ├──▶ agentLoop(steeringQueue, context, config)
    │       │       │
    │       │       ├──▶ runAgentLoop()
    │       │       │       │
    │       │       │       ├──▶ emit("agent_start")
    │       │       │       ├──▶ emit("turn_start")
    │       │       │       ├──▶ emit("message_start", prompt)
    │       │       │       ├──▶ emit("message_end", prompt)
    │       │       │       ├──▶ runLoop()
    │       │       │       └──▶ emit("agent_end")
    │       │       │
    │       │       └──▶ EventStream 返回给 Agent
    │       │
    │       ├──▶ 监听 stream 事件
    │       │       └─▶ 更新 this._state.streamMessage
    │       │
    │       └──▶ stream.result() → Promise<AgentMessage[]>
    │               └─▶ 保存到 this._newMessages
    │
    └──▶ 返回 Promise<void> (立即)
```

### 代码追踪

| 调用栈 | 代码/事件 | 类型/结构定义 | 疑问 & 答案 |
|--------|-----------|---------------|-------------|
| User 调用 | `agent.prompt({ role: "user", content: "hi" })` | `agent.ts` | Q: 同步还是异步？ |
| └─> `this.enqueueSteeringMessage(message)` | `agent.ts:enqueueSteeringMessage` | `AgentMessage[]` | A: 立即入队 |
| └─> `if (!this.runningPrompt)` | `agent.ts:startAgentLoop` | `Promise<void> \| undefined` | Q: loop 运行中？ |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> `this.runningPrompt = this.startAgentLoop()` | - | `Promise<void>` | A: 启动新 loop |
| └─> `agentLoop(steeringQueue, ...)` | `agent-loop.ts:agentLoop` | `EventStream<AgentEvent, AgentMessage[]>` | - |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> `runAgentLoop(prompts, ...)` | `agent-loop.ts:runAgentLoop` | `Promise<AgentMessage[]>` | - |
| &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;└─> `emit({ type: "agent_start" })` | 事件发射 | `AgentEvent` | - |
| &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;└─> `runLoop(currentContext, newMessages, config, ...)` | `agent-loop.ts:runLoop` | `void` | Q: 核心循环？ |
| &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;└─> 双循环结构 | - | - | A: Outer + Inner |
| 返回 | `Promise<void>` | - | A: 事件通过回调 |

## 调用链 2: runLoop (核心双循环)

### 调用路径

```
runLoop(context, newMessages, config, signal, emit, streamFn)
    │
    ├──▶ Outer Loop: while (true)
    │       │
    │       ├──▶ hasMoreToolCalls = true
    │       │
    │       ├──▶ Inner Loop: while (hasMoreToolCalls || pendingMessages.length > 0)
    │       │       │
    │       │       ├──▶ 如果不是 firstTurn: emit("turn_start")
    │       │       │
    │       │       ├──▶ 处理 pendingMessages (steering)
    │       │       │       ├─▶ emit("message_start/end")
    │       │       │       └─▶ 添加到 context
    │       │       │
    │       │       ├──▶ streamAssistantResponse()
    │       │       │       │
    │       │       │       ├──▶ transformContext() (如果配置)
    │       │       │       ├──▶ convertToLlm()
    │       │       │       ├──▶ streamSimple() → AssistantMessage
    │       │       │       └──▶ emit("message_start/update/end")
    │       │       │
    │       │       ├──▶ 检查 tool calls
    │       │       │       └─▶ message.content.filter(c => c.type === "toolCall")
    │       │       │
    │       │       ├──▶ 如果有 tool calls:
    │       │       │       │
    │       │       │       ├──▶ executeToolCalls()
    │       │       │       │       │
    │       │       │       │       ├──▶ 对每个 tool call:
    │       │       │       │       │       │
    │       │       │       │       │       ├──▶ validateToolArguments()
    │       │       │       │       │       │
    │       │       │       │       │       ├──▶ beforeToolCall() hook
    │       │       │       │       │       │
    │       │       │       │       │       ├──▶ 如果被 block:
    │       │       │       │       │       │       └─▶ 创建 error result
    │       │       │       │       │       │
    │       │       │       │       │       ├──▶ emit("tool_execution_start")
    │       │       │       │       │       │
    │       │       │       │       │       ├──▶ tool.execute()
    │       │       │       │       │       │       └─▶ 工具实际执行
    │       │       │       │       │       │
    │       │       │       │       │       ├──▶ emit("tool_execution_update") (流式)
    │       │       │       │       │       │
    │       │       │       │       │       ├──▶ emit("tool_execution_end")
    │       │       │       │       │       │
    │       │       │       │       │       └──▶ afterToolCall() hook
    │       │       │       │       │
    │       │       │       │       └──▶ 收集所有 results
    │       │       │       │
    │       │       │       └──▶ 添加 results 到 context
    │       │       │
    │       │       ├──▶ emit("turn_end")
    │       │       │
    │       │       └──▶ pendingMessages = getSteeringMessages()
    │       │
    │       ├──▶ 检查 follow-up messages
    │       │       └─▶ followUpMessages = getFollowUpMessages()
    │       │
    │       ├──▶ 如果有 followUp: pendingMessages = followUpMessages
    │       │
    │       └──▶ 否则: break Outer Loop
    │
    └──▶ emit("agent_end")
```

### 代码追踪

| 调用栈 | 代码/事件 | 类型/结构定义 | 疑问 & 答案 |
|--------|-----------|---------------|-------------|
| 进入 | `runLoop(context, newMessages, config, ...)` | `agent-loop.ts:runLoop` | - |
| └─> `while (true)` | Outer Loop | - | Q: 何时退出？ |

| └─> `while (hasMoreToolCalls \|\| pendingMessages.length)` | Inner Loop | - | Q: 一轮对话？ |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> 是 | - | - | A: 一个 turn |
| └─> `streamAssistantResponse(context, config, ...)` | `agent-loop.ts:streamAssistantResponse` | `AssistantMessage` | - |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> `config.transformContext?.(messages)` | 可选变换 | `AgentMessage[]` | Q: 用途？ |
| &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;└─> 上下文裁剪 | - | - | A: token 管理 |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> `config.convertToLlm(messages)` | 消息转换 | `Message[]` | Q: 为什么转换？ |

| &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;└─> `type === "toolCall"` | - | - | A: content 中的 |

| &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;└─> AJV 验证 | - | - | A: 参数校验 |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> `beforeToolCall?.(context, signal)` | hook | `BeforeToolCallResult` | Q: 阻止执行？ |
| &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;└─> `{ block: true }` | - | - | A: 可以 |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> `tool.execute(toolCallId, params, ...)` | - | `Promise<AgentToolResult>` | - |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> `afterToolCall?.(context, signal)` | hook | `AfterToolCallResult` | Q: 修改结果？ |

## 调用链 3: executeToolCalls (工具执行)

### 调用路径

```
executeToolCalls(context, assistantMessage, config, signal, emit)
    │
    ├──▶ toolCalls = assistantMessage.content.filter(c => c.type === "toolCall")
    │
    ├──▶ results: ToolResultMessage[] = []
    │
    ├──▶ 如果 config.toolExecution === "parallel":
    │       │
    │       ├──▶ 步骤 1: Preflight (顺序)
    │       │       │
    │       │       └──▶ 对每个 tool call:
    │       │               │
    │       │               ├──▶ validateToolArguments()
    │       │               │
    │       │               ├──▶ beforeToolCall()
    │       │               │
    │       │               ├──▶ 如果被 block:
    │       │               │       └─▶ 加入 blocked 列表
    │       │               │
    │       │               └──▶ 否则: 准备执行
    │       │                       └─▶ { tool, args, toolCall }
    │       │
    │       ├──▶ 步骤 2: Execute (并行)
    │       │       │
    │       │       ├──▶ 对准备好的工具:
    │       │       │       └─▶ Promise.all(tools.map(t => executeOne(t)))
    │       │       │
    │       │       └──▶ 对每个执行:
    │       │               │
    │       │               ├──▶ emit("tool_execution_start")
    │       │               │
    │       │               ├──▶ tool.execute()
    │       │               │
    │       │               ├──▶ emit("tool_execution_update") (如果有 onUpdate)
    │       │               │
    │       │               └──▶ emit("tool_execution_end")
    │       │
    │       └──▶ 步骤 3: Finalize (顺序)
    │               │
    │               └──▶ 对每个结果:
    │                       │
    │                       ├──▶ afterToolCall()
    │                       │
    │                       ├──▶ createToolResultMessage()
    │                       │
    │                       └──▶ results.push(resultMessage)
    │
    ├──▶ 否则 (sequential):
    │       │
    │       └──▶ 对每个 tool call (顺序):
    │               │
    │               ├──▶ validateToolArguments()
    │               ├──▶ beforeToolCall()
    │               ├──▶ emit("tool_execution_start")
    │               ├──▶ tool.execute()
    │               ├──▶ emit("tool_execution_end")
    │               ├──▶ afterToolCall()
    │               └──▶ results.push(resultMessage)
    │
    └──▶ 返回 results


### 代码追踪 (Parallel 模式)

| 调用栈 | 代码/事件 | 类型/结构定义 | 疑问 & 答案 |
|--------|-----------|---------------|-------------|
| 进入 | `executeToolCalls(context, message, config, ...)` | `agent-loop.ts` | - |
| └─> 如果 `parallel` | `config.toolExecution` | `"parallel" \| "sequential"` | Q: 默认？ |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> `parallel` | 默认 | - | A: 默认并行 |
| └─> Preflight | 顺序遍历 | - | Q: 为什么顺序？ |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> 验证和 hook 需要顺序 | - | - | A: 验证依赖 |
| └─> `Promise.all(executions)` | 并行执行 | `Promise<AgentToolResult>[]` | Q: 并发安全？ |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> 是 | - | - | A: 工具独立 |
| └─> Finalize | 顺序处理 | - | Q: 为什么顺序？ |
| &nbsp;&nbsp;&nbsp;&nbsp;└─> afterToolCall 可能依赖顺序 | - | - | A: 保证顺序 |
| 返回 | `ToolResultMessage[]` | - | A: 按原始顺序 |

## 调用链 4: streamProxy (代理服务器)

### 调用路径

```
streamProxy(model, context, options: ProxyStreamOptions)
    │
    ├──▶ 创建 ProxyMessageEventStream
    │
    ├──▶ (async) 发送 HTTP POST 请求到 proxy
    │       │
    │       ├──▶ fetch(`${options.proxyUrl}/api/stream`, {...})
    │       │       │
    │       │       ├──▶ headers: { Authorization: `Bearer ${authToken}` }
    │       │       │
    │       │       ├──▶ body: JSON.stringify({ model, context, options })
    │       │       │
    │       │       └──▶ signal: options.signal
    │       │
    │       ├──▶ 如果 response.ok === false:
    │       │       └─▶ throw Error
    │       │
    │       ├──▶ 获取 reader
    │       │       └─▶ response.body.getReader()
    │       │
    │       └──▶ 循环读取 SSE 流:
    │               │
    │               ├──▶ reader.read()
    │               │
    │               ├──▶ decode chunk
    │               │
    │               ├──▶ parse JSON
    │               │
    │               ├──▶ 重建 partial message
    │               │       └─▶ Proxy 只发 delta，客户端重建
    │               │
    │               └──▶ stream.push(event)
    │
    └──▶ 返回 stream (立即)
```

```

    │
    └──▶ this._state.model = model

    │
    └──▶ this._state.systemPrompt = prompt

    │
    └──▶ this._state.tools.push(tool)

    │
    └──▶ this.listeners.add(listener)

    │
    └──▶ this.listeners.delete(listener)

    │
    ├──▶ 对每个 listener:
    │       └─▶ listener(event)
    │
    └──▶ 更新内部状态 (如 streamMessage)
            │
            ├──▶ if event.type === "message_update":
            │       this._state.streamMessage = event.message
            │
            └──▶ if event.type === "message_end":

```
## 调用链 6: convertToLlm (消息转换)

### 调用路径

```
defaultConvertToLlm(agentMessages)
    │
    └──▶ agentMessages.filter(m => 
            m.role === "user" ||
            m.role === "assistant" ||
            m.role === "toolResult"
        )

// coding-agent 自定义实现:
convertToLlm(agentMessages)
    │
    ├──▶ agentMessages.flatMap(m => {
    │       if (m.role === "custom") {
    │         // 自定义消息 → 用户消息

    │       }

    │         // UI 通知 → 过滤掉

    │       }
    │       // 标准消息 → 直接通过
    │       return [m]
    │    })

## 关键调用链总结

| 场景 | 入口 | 核心路径 | 出口 |
|------|------|----------|------|
| **发送消息** | `agent.prompt()` | `enqueue → startLoop → agentLoop → runLoop` | `void` (事件) |
| **核心循环** | `runLoop()` | `Outer Loop → Inner Loop → stream → executeTools` | `emit("agent_end")` |
| **LLM 调用** | `streamAssistantResponse()` | `transform → convert → streamSimple → emit` | `AssistantMessage` |
| **工具执行** | `executeToolCalls()` | `validate → before → execute → after → results` | `ToolResultMessage[]` |
| **Proxy 调用** | `streamProxy()` | `fetch → read SSE → push events` | `EventStream` |
| **状态更新** | `agent.setXxx()` | `update _state → emit` | `void` |
| **消息转换** | `convertToLlm()` | `filter/map → Message[]` | `Message[]` |
| **上下文变换** | `transformContext()` | `prune/inject → AgentMessage[]` | `AgentMessage[]` |
